# Arduino 카드 리더기 테스트 코드 위치

현재 사용자 작업 트리의 진단 스케치는 `card_reader_test.ino`다. MFRC522 카드 UID를
출력하는 코드이며 컴파일·실제 기기 인식·웹 연동은 아직 검수하지 않았다.
폴더명과 주 스케치 이름을 맞추는 작업은 MVP-01에서 진행하며 이번 계획 정리에서는 변경하지 않는다.

코드를 추가할 때 아래 내용을 함께 채운다.

| 항목 | 상태 |
|---|---|
| Arduino 보드 모델 | UNO R4 WiFi — 사용자 확인 |
| 카드 리더기 모델·연결 방식 | RC522/SPI — 현재 코드 기준, 실제 모듈 검수 필요 |
| 배선·필요 라이브러리 | SS 10/RST 9, SPI.h/MFRC522.h — 실제 배선·전압·버전/호환성 검수 필요 |
| 시리얼 통신 속도·출력 예시 | 115200bps, 상태 문구와 UID — 현재 코드 기준, 웹용 프로토콜은 후속 |
| 컴파일·업로드·카드 인식 결과 | 미실행 |

실제 아동 정보나 개인 카드와 연결된 식별값 목록은 예제·로그로 커밋하지 않는다.
2026-10-26 폴더 준비 후 사용자 파일과 환경을 확인했다. 테스트·컴파일·기기 연결은 실행하지 않았다.
