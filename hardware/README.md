# 하드웨어 확장

Arduino 등 외부 기기의 코드와 배선·실행 안내를 웹 클라이언트·API와 분리해 보관한다.
현재는 코드 입력을 위한 폴더만 준비했으며 카드 인식이나 웹 연동을 구현한 상태가 아니다.

## Arduino 카드 리더기

[카드 리더기 테스트 폴더](arduino/card-reader-test/README.md)에 스케치를 추가한다.
예정 경로는 `hardware/arduino/card-reader-test/card-reader-test.ino`다.
보드·리더기 모델·연결 방식이 정해진 뒤 배선·필요 라이브러리·시리얼 출력 형식을 기록한다.
현재 특정 보드나 리더기 라이브러리를 가정하거나 설치하지 않는다.

기기에서 카드 읽기와 식별값 출력부터 확인하고, 웹 카드 선택·음성 출력 연동은 별도 작업으로
진행한다. 하드웨어의 실제 검수와 기존 npm 자동 검증 결과를 구분한다.

## 작업 기록 — 2026-10-26

사용자 요청으로 폴더와 안내 문서만 생성한다. README로 폴더를 Git에 보관하며 빈 스케치나
동작하지 않는 예제 코드를 추가하지 않는다. 사용자 요청에 따라 추가 테스트는 실행하지 않는다.
Arduino 컴파일·업로드·실제 카드 인식·웹 연동·앱 테스트/빌드는 모두 **미실행**이다.
