# PECS MATE 발표 예상 질문과 답변

구현·통신·AI·캐시 등 기술 질문은 [기술 질문 대비](presentation-technical-qa.md)를 참고합니다.

3분 발표 뒤의 질의응답용 자료입니다. 먼저 굵은 문장으로 답하고,
추가 질문이 있을 때만 나머지 설명을 붙입니다. 질문 하나당 15~25초를 목표로 연습합니다.
실제로 확인하지 않은 사용자 평가·치료 효과·성능 수치는 말하지 않습니다.

## 먼저 외울 질문 5개

### 1. 누구를 위한 서비스인가요

**말로 자신의 의사를 표현하기 어려운 아동이 그림으로 표현하도록 돕는 서비스입니다.**
아동은 카드 선택과 말하기를 사용하고, 보호자와 담당자는 카드 등록과 설정을 돕습니다.
모든 아동에게 같은 방식이 적합하다고 전제하지 않고 개인에게 맞게 준비하는 방향입니다.

### 2. PECS가 무엇인가요

**그림카드를 상대방에게 건네며 원하는 것을 표현하는 그림교환 의사소통 방식입니다.**
예를 들어 물을 원할 때 물 그림카드로 뜻을 전달하는 식입니다.
가져온 실제 사용 카드를 보여주면서 설명합니다. 저희 앱 자체가 공식 PECS 프로그램으로
인증됐다는 뜻은 아닙니다.

### 3. 기존 그림카드나 다른 AAC 앱과 무엇이 다른가요

**저희 프로젝트의 초점은 익숙한 실물 카드를 디지털 카드·문장·음성과 연결하는 것입니다.**
맞춤 카드 등록·편집·인쇄와 RFID 연결을 한 흐름으로 구성했습니다.
모든 기존 앱보다 우수하다거나 다른 앱에는 이 기능이 없다고 주장하지 않습니다.

### 4. AI가 꼭 필요한가요

**기본 표현은 AI 없이도 가능하고, AI는 카드의 뜻을 자연스러운 문장으로 다듬는 역할입니다.**
카드에 없는 내용을 보태지 않도록 지침을 주고 의미와 안전 항목을 검증합니다.
연결 오류나 검증 실패가 생기면 규칙 기반 문장으로 대체합니다.
검증이 모든 잘못된 출력을 완전히 막는다는 뜻은 아닙니다.

### 5. RFID를 왜 사용했나요

**화면을 누르는 방법 외에, 실물 카드를 대는 방법으로도 디지털 화면과 연결하기 위해서입니다.**
칩 UID를 미리 등록한 그림카드와 연결하고, 스캔하면 해당 카드를 조회합니다.
누구에게 더 편한지는 실제 사용자의 특성에 맞춰 평가해야 합니다.

## 기능과 시연 질문

### 6. 칩에 그림이나 문장을 저장하나요

**현재 구현은 칩의 식별번호인 UID와 서버의 카드 연결 정보를 사용합니다.**
칩에서 그림이나 문장 자체를 읽는 방식은 아닙니다. 미등록 칩이면 미등록으로 표시합니다.

### 7. 리더기를 세 개 쓰는 이유는 무엇인가요

**여러 위치에 놓인 카드를 구분해 읽는 구성을 시험하기 위해서입니다.**
프로젝트 펌웨어는 리더 1~3개 설정을 지원합니다. 실제 발표에서는 정상 동작을 확인한
구성으로 시연하며, 모든 배치에서 안정적으로 동작한다고 단정하지 않습니다.

### 8. 인터넷이 없으면 사용할 수 없나요

**미리 저장된 카드·음성 등 일부 기능은 사용할 수 있지만, 클라우드 문장 생성은 인터넷이 필요합니다.**
현재 OpenRouter API는 서버 PC에서 인터넷으로 연결합니다.
인터넷이 끊겼을 때의 전체 동작은 저장된 자료와 실제 기기 조건에 따라 확인해야 합니다.

### 9. 문장 생성이 느리면 어떻게 하나요

**로컬 모델 대신 OpenRouter의 Qwen 모델로 문장을 생성하도록 바꿨습니다.**
개인정보 없는 예제 호출에서는 약 0.86~1.34초를 확인했습니다.
이는 문장 생성만의 측정값으로 음성 합성·재생 시간은 포함하지 않으며,
인터넷과 서버 부하에 따라 달라집니다.

### 10. 음성도 Qwen API인가요

**문장 생성과 음성 생성은 별개입니다. 현재 적용한 API 전환은 문장 생성입니다.**
최근 확인한 실행 구성에서 음성은 MeloTTS를 사용했습니다.
Qwen 음성 API 연결 코드는 준비했지만 실제 전환과 청음 검증을 완료한 것은 아닙니다.
발표 직전 실행 설정을 다시 확인합니다.

### 11. 비용은 얼마나 드나요

**사용한 모델과 요청량에 따라 과금되며, 짧은 문장은 적은 토큰으로 생성됩니다.**
초기 확인한 대시보드에는 4회 요청·약 1.37K 토큰이 표시됐습니다.
지출이 0달러로 보였더라도 무료라고 단정하지 않습니다.
하루 3만 원 예산을 고려했으며, 실제 사용량과 계정 한도로 관리해야 합니다.
충전 수수료·세금·음성 비용까지 모두 포함한 확정 견적은 아닙니다.

### 12. 사용자 사진이나 개인정보도 외부 AI에 보내나요

**현재 문장 생성 요청에는 선택한 카드의 이름과 문장 생성 지침이 전송됩니다.**
API 키는 백엔드에서만 사용합니다. 카드명 자체에도 개인정보가 들어갈 수 있으므로
개인정보를 전혀 보내지 않는다고 말하지 않습니다.
사진 기반 이미지 처리 기능은 문장 생성과 별도의 전송 경로를 확인해야 합니다.

## 검증과 한계 질문

### 13. 실제 아동에게 효과가 있었나요

**현재 확인한 것은 구현과 기능 동작이며, 치료 효과를 입증한 서비스는 아닙니다.**
실제 아동 대상 효과 검증과 사용성 평가는 별도의 절차와 근거가 필요합니다.
관찰하거나 측정하지 않은 효과를 발표에서 주장하지 않습니다.

### 14. 그림카드의 저작권은 어떻게 되나요

**일부 그림상징에는 별도 저작권과 이용 제한이 있어 출처별로 구분해야 합니다.**
사용자가 제시한 일부 자료의 출처는 ‘한국형 보완대체의사소통용 기본상징 체계집’이며,
모든 카드에 같은 출처나 허용 조건을 적용할 수는 없습니다.
배포·상업 이용 허가를 확보했다고 확인되지 않은 상태에서 허가됐다고 답하지 않습니다.

### 15. 앞으로 무엇을 개선할 계획인가요

**실제 사용 환경에서 안정성과 사용성을 확인하고, 사용자별 학습지 제작을 확장할 계획입니다.**
현재 구현한 카드·문장·음성·RFID 기능과 향후 계획인 학습지 제작을 구분해서 설명합니다.

## 답하기 어려울 때 사용할 문장

> 그 부분은 아직 검증하지 못했습니다. 현재 확인한 범위는 여기까지이며,
> 실제 사용자와 사용 환경을 기준으로 추가 확인할 계획입니다.

> 문장 생성 성공과 실제 기기에서 소리가 나는 것은 별도여서,
> 각각 나눠 확인하고 있습니다.

> 현재 구현한 내용과 향후 계획을 구분해서 말씀드리겠습니다.

## 발표 직전 확인

- [ ] 아동과 보호자·담당자의 역할을 구분해 답할 수 있다.
- [ ] AI가 하는 일과 규칙 기반 대체를 설명할 수 있다.
- [ ] 실제로 측정한 문장 생성 시간과 전체 음성 시작 시간을 혼동하지 않는다.
- [ ] 현재 실행 중인 음성 제공자를 확인했다.
- [ ] 사용자 평가·치료 효과·저작권 허가를 과장하지 않는다.
- [ ] 비용 질문에는 현재 대시보드를 확인하고 답한다.
