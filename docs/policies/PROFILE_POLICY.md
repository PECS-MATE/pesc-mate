# 사용자 프로필 정책

## 종류와 저장

- 핑크, 오렌지, 하늘, 크림, 그린, 블루, 우주 PESC MATE 캐릭터 이미지와 직접 등록을 지원한다.
- 회원가입 직후 또는 기존 계정의 최초 로그인에서 프로필을 선택한다. 프로필이 없으면 기능 화면 진입 전에 선택 화면을 표시한다.
- 모든 역할은 본인 프로필만 변경할 수 있다. 설정 저장 후 홈과 사이드바에 즉시 반영한다.
- 이름·프로필 사진을 누르면 마이페이지 창이 열린다. 프로필과 역할별 설정 진입점은
  [마이페이지 안내](../development/MY_PAGE_SETTINGS.md)를 따른다.
- MongoDB users.profile에 저장한다. 로그인, 인증 정보 조회, 보호자의 연결 사용자 조회 응답에 프로필을 포함한다.
- 2026-10-22부터 신규 직접 등록의 검증된 원본을 `users.profile.original_image`에 화면용 WebP와 함께 보관한다. 로컬 MongoDB 볼륨을 재사용하며 클라우드 저장소를 추가하지 않는다.
- 원본은 바이트·실제 MIME·크기·SHA-256을 보관하고 원본 파일명은 보관하지 않는다. EXIF 위치·기기 정보가 남을 수 있으므로 화면·안전성 검사·프로필 JSON·개인정보 JSON 내보내기로 제공하지 않는다.
- 변경 시 기존 화면용 이미지와 원본을 한 번의 프로필 갱신으로 대체한다. 기본 캐릭터로 바꾸거나 개인정보를 삭제하면 원본도 제거하며 이전 프로필 원본 이력은 쌓지 않는다. 별도 백업의 기존 사본은 이 요청으로 자동 삭제되지 않는다.

## 직접 등록 이미지

- JPG, PNG, WebP만 허용한다. 5MB 이하, 가로·세로 각각 128~4096px, 총 1600만 픽셀 이하로 제한한다.
- 서버에서 실제 형식과 선언 MIME 일치, 파일 디코딩과 해상도를 검증한다. EXIF 방향 보정 후 메타데이터를 제거하고 WebP로 정규화한다.
- 원본과 WebP의 합은 문서 저장 안전 여유를 위해 15MiB 이하로 제한하며 초과 시 기존 프로필을 유지하고 422를 반환한다. 사용자별·서비스 전체 저장량 정책을 완료한 것은 아니다.
- 기존 IMAGE_SAFETY_API_URL과 IMAGE_SAFETY_API_TOKEN 설정을 재사용한다. 검사 결과가 passed인 경우에만 저장한다.
- 차단, 검사 공급자 미설정, 검사 장애에 따른 manual_review 결과는 저장하지 않는다. 기존 프로필을 유지하고 기본 캐릭터 선택을 안내한다.
- MVP에서는 프로필 사진의 운영 담당자 수동 승인 대기열을 제공하지 않는다. 따라서 검사 공급자가 없으면 직접 등록을 완료할 수 없다.
- 이미지는 인증된 본인 또는 연결된 보호자만 조회할 수 있다. 담당자의 전체 운영 권한만으로는 다른 계정의 사진을 조회할 수 없다.
- 화면용은 512px 이내, 썸네일은 128px 이내로 비율을 보존한다. Avatar는 버전별 썸네일을 우선 사용한다.
- 사진 응답은 private, no-cache와 ETag를 사용한다. 304도 매번 인증·현재 권한·문서 존재를 확인한다. 교체·삭제된 예전 이미지를 그대로 재사용하는 캐시는 허용하지 않는다.
- 원본 다운로드 API는 제공하지 않는다. 원본은 로컬 DB·전체 DB 백업 안의 보관용이며, 로그인·현재 인증 조회는 이미지 바이너리를 읽지 않는다. 기존 업로드의 사라진 원본을 재생성하지 않는다.

## API

- GET /api/profile/presets: 사용 가능한 기본 프로필 id와 label 목록.
- PUT /api/profile: JSON {"preset":"pink"}로 본인 프로필 변경.
- POST /api/profile/image: multipart image 파일로 본인 프로필 변경.
- GET /api/profile/{user_id}/image: 권한 검사 후 WebP 반환.
- 로그인과 /api/auth/me, /api/care/linked-users의 사용자 객체에 profile을 추가한다.
- profile은 미설정 시 null, 기본 선택 시 kind=preset 및 preset, 사진 선택 시 kind=custom 및 image_url을 포함한다.
- 잘못된 입력은 422, 미인증은 401, 타인 접근은 403, 이미지 없음은 404, 저장소 오류는 503으로 응답한다.
- `?variant=thumbnail`은 썸네일, 기본값 `display`는 화면용이다. 원본 variant는 제공하지 않는다. 저장 한도 초과는 413, 이미지 쓰기 진행·삭제 경쟁은 409이며 기존 프로필을 보존한다.
- 기본 이미지 저장 한도·직렬화 잠금·정리·백업 30일 보존과 삭제 이전 복원 차단은 [로컬 이미지 저장](../development/LOCAL_IMAGE_STORAGE.md)을 따른다.

## 마스코트 적용

기존 원본이 없어 새 마스코트를 생성하고 로그인·Home·빈 상태·도움말에 적용했다.
자산 경로와 생성 프롬프트는 [마스코트 자산 문서](../development/MASCOT_ASSET.md)를 참고한다.
