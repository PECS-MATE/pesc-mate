# 복구 표현 정책

## 목적

복구 표현은 잘못 전달한 의사를 빠르게 취소하거나 상대에게 기다려 달라고 요청하는
의사소통 안전 기능이다. 학습 점수나 성취로 해석하지 않으며, 일반 추천 결과로 위치를
바꾸지 않는다.

## 기본 구성

- 필수 고정 표현: `잘못 눌렀어요`, `그 뜻이 아니에요`
- 기본 선택 표현: `잠깐만요`, `다시 말할게요`
- 교체 가능 표현: `제 말을 기다려 주세요`, `질문을 잘 모르겠어요`, `맞아요`, `아니에요`

필수 표현 두 개는 보호자나 담당자도 제거할 수 없다. 선택 표현은 권한이 있는
보호자·담당자가 최대 두 개까지 골라 전체 복구 영역을 2~4개로 구성한다. 위치는
명시적으로 저장한 순서를 유지한다.

## 실패 시 동작

- 발화를 시작하기 전에 선택한 표현을 화면 상태에 보존한다.
- 음성이 재생되지 않으면 전달하려던 문구를 오류 영역에 그대로 표시한다.
- 재시도 가능 오류에는 `다시 재생`을 제공한다.
- 음량 0이나 기기 음성 미설치 상태에는 설정 확인 방법을 안내한다.
- 네트워크 기록 저장 실패는 기기 음성 재생을 막지 않는다.
- 로그인 직후 복구 표현 8개를 포함한 기본 음성을 자동 재생 없이 기기에 저장한다. 오프라인·한국어 음성 없음·기기 TTS 실패 시 저장된 음성으로 재생한다. 사용자 지정 문장은 고정 음성 묶음에 포함하지 않는다.

## 현장 확정 항목

현재 필수·선택 구분은 자동 검증을 위한 제품 기준선이다. 실제 보호자·담당자 검수에서
표현 이해도와 두 번 이하 선택 가능 여부를 확인한 뒤 문구를 최종 확정한다. Android와
iPadOS에서 앱을 완전히 종료한 오프라인 콜드 스타트 음성 재생은 별도 실기 검증으로
남긴다.
