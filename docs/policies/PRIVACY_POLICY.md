# 아동 기록과 개인 카드 통제 정책

## 기본 원칙

PESC MATE는 아동의 표현을 진단 자료로 단정하지 않으며, 필요한 최소 정보만 계정별로 분리한다. 법정대리인 동의 여부와 정책 버전·시각을 저장하고, 사용자는 30일·90일·1년·3년 중 기록 보존 기간을 선택한다. 실제 운영 전 개인정보 처리방침, 담당자 연락처와 법률 검토를 별도로 확정해야 한다.

법정대리인 동의 전에도 기본 카드 탐색과 브라우저의 즉시 발화는 사용할 수 있지만 문장·음성 이력과 개인 카드는 서버에 저장하지 않는다. 동의하지 않았다는 이유로 긴급 의사표현 기능을 막지 않는다.

## 개인 카드와 공개 카드

- 개인 카드는 이미지 형식·크기·안전성 검사 후 운영 권한 담당자에게 내용과 이미지를 공유하지 않고 본인에게 즉시 활성화한다.
- 공개 카드는 운영 권한 담당자의 승인 전까지 다른 사용자에게 노출하지 않는다. 승인된 공개 카드만 전체 카드 목록에 포함한다.
- 개인 카드 화면에는 `나만 사용 · 운영 담당자에게 공유되지 않음`을 표시한다.
- 보호자·담당자는 AAC 사용자가 직접 부여한 `cards_manage` 연결 권한이 있을 때만
  해당 사용자의 개인 카드를 등록·수정할 수 있다. 카드 소유자는 AAC 사용자로,
  감사 기록의 처리자는 실제 보호자·담당자 계정으로 남긴다.
- 개인 표현은 의사소통 권리를 위해 욕설이나 위기 표현만을 이유로 차단하지 않는다. 다만 불법 이미지나 안전성 검사를 통과하지 못한 이미지는 차단한다.
- 공개 콘텐츠에는 서비스 전체 사용자를 보호하기 위한 표현 제한과 언어·이미지 검토를 적용한다. 개인 표현을 공개로 전환하면 공개 기준으로 다시 검사하고 승인받는다.

## 보호자 열람

AAC 사용자는 개인정보 화면에서 현재 연결된 보호자와 열람 범위를 확인한다. 연결 범위는 이용 현황, 의사소통 기록, 프로필 이미지, 보호자 메모로 고정하며 연결·해제와 데이터 삭제는 변경 이력에 기록한다. 연결 해제 즉시 보호자의 대시보드·프로필 이미지·메모 접근이 중단된다.

보호자·담당자 계정과 연결 아동의 화면 데이터는 오프라인 사용을 위해 기기에
저장하지 않는다. 네트워크가 끊기면 열려 있던 아동별 카드·기록·설정 상태를
폐기하고, 다시 연결한 뒤 서버에서 현재 연결과 권한을 확인해야 조회할 수 있다.

## 다운로드·보존·삭제

사용자는 계정 정보, 문장·음성 이력, 개인 카드 메타데이터와 지원 연결 목록을 JSON으로 다운로드할 수 있다. 비밀번호 해시, 인증 토큰과 이미지 바이너리는 내보내지 않는다.

보존 기간을 줄이면 이미 기간이 지난 문장·음성 이력을 복구 불가능하게 삭제한다. `이용 데이터 삭제`는 개인 카드와 감사 이력, 문장·음성 기록, 보호자 메모·연결, 프로필 이미지와 사용자 설정을 삭제한다. 로그인 계정과 삭제 완료 시각은 결과 확인을 위해 유지한다. 계정 자체 폐기가 필요한 운영 환경에서는 본인·법정대리인 확인 후 별도 계정 폐기 절차를 제공해야 한다.

## 운영 점검

- 개인 카드가 운영 승인 화면이나 다른 사용자 검색에 나타나지 않는지 확인한다.
- 보호자 연결 해제 직후 기존 URL로 기록·이미지에 접근할 수 없는지 확인한다.
- 다운로드 파일에 이미지 원본, 비밀번호, 인증 토큰이 없는지 확인한다.
- 삭제 후 개인 카드, 기록, 메모, 연결과 설정이 다시 조회되지 않고 완료 상태만 보이는지 확인한다.
