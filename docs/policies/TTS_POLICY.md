# TTS MVP 정책

## 선정 결과

- 공급자: 브라우저 Web Speech API (`speechSynthesis`)
- 음성: 사용자 기기에 설치된 한국어 음성을 우선 사용한다. 기본 긴급·복구 표현은 기기 음성이 없거나 실패할 때 저장된 WAV로 재생한다.
- 비용: 외부 TTS API를 호출하지 않으므로 별도 사용료가 없다.
- 적용 범위: 카드 단어, 생성 문장, 설정 미리 듣기에 동일한 설정을 사용한다.
- 저장: 프리셋, 기기 음성 이름, 속도, 음높이 및 기본 볼륨을 MongoDB에 사용자별로 저장한다.
- 측정: 발화 원문 없이 콘텐츠 종류, 성공 여부, 오류 코드와 발화 시작 지연 시간만 저장한다.

## 음성 프리셋

| 프리셋 | 기본 속도 | 기본 음높이 |
|---|---:|---:|
| 어린이 느낌 | 0.90 | 1.25 |
| 여성 느낌 | 0.95 | 1.05 |
| 남성 느낌 | 0.85 | 0.80 |

프리셋은 기기 음성의 속도와 음높이를 조정하는 MVP 기능이다. 실제 어린이·여성·남성 성우 음색을 보장하지 않으며, 사용 가능한 음성 이름과 품질은 운영체제 및 브라우저에 따라 달라진다.

## 장애 및 대체 방식

1. 선택한 기기 음성을 찾지 못하면 첫 번째 한국어 음성을 사용한다.
2. 기본 긴급·복구 표현은 오프라인이거나 한국어 음성이 없으면 저장된 WAV를 먼저 사용한다. 그 외 표현은 브라우저 기본 음성을 시도한다.
3. 기기 TTS 오류 또는 2.5초 시작 시간 초과 시 해당 표현의 WAV로 한 번 대체한다. 사용자 취소는 대체 재생하지 않는다. WAV도 실패하면 기존 카드와 문장을 유지하고 재시도 안내를 표시한다.
4. 실제 연령·성별 음색 보장이 필요해지면 서버 TTS 공급자를 별도 비교하고 사용자 동의, 비용 한도, 네트워크 실패 대체 정책을 추가한다.

## 기본 표현 사전 음성

- 범위: 기본 빠른 표현 5개와 복구 표현 8개. 사용자 입력 문장, 개인 카드 문구와 녹음은 포함하지 않는다.
- 자산: `frontend/public/audio/core/v1/manifest.json`과 16kHz·16bit·mono PCM WAV 13개, 합계 약 800KB.
- 생성: Windows의 `Microsoft Heami Desktop` 음성으로 `scripts/generate-core-speech.ps1`을 실행한다. 스크립트는 `App.jsx`의 기본 표현 목록을 읽고 WAV 형식과 크기를 검사한다. 사용자 발화를 외부 TTS로 전송하지 않는다.
- 준비: AAC 사용자 로그인 직후 비동기로 내려받아 IndexedDB `coreSpeech`에 저장한다. 로그인·카드 조회 완료를 기다리게 하거나 자동 재생하지 않는다.
- 실패: 일부 다운로드나 저장 공간 부족 시 재생 가능한 파일은 유지하고 실제 저장 개수를 표시한다. 다시 준비하면 누락 파일만 요청한다. 오프라인 복원 도중 재연결되어도 누락 파일을 준비한다.
- 재생 설정: 사전 음성은 속도와 볼륨을 적용하며 기기 음성 선택·음높이는 적용하지 않는다. 미리 듣기는 기기 TTS를 사용한다.
- 삭제: 공용 고정 문구만 저장하므로 로그아웃·사용자 데이터 삭제 뒤에도 재사용한다. 사이트 데이터 삭제 시 제거된다. 사용자별 기록·스냅샷 삭제 정책은 유지한다.
- 교체: 문구나 음성을 변경하면 자산 경로·manifest·`CORE_SPEECH_VERSION`을 함께 올린다. 구버전 묶음은 읽지 않고 새 묶음 저장 시 교체한다.
- 검증 한계: 생성 도구와 음성 자산의 외부 배포 사용 조건은 운영 배포 전 라이선스 검토 항목에 포함한다. 자동 테스트 통과만으로 실기 지원을 선언하지 않는다.
