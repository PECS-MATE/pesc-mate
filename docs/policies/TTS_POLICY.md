# TTS 정책

> 2026-11-11 갱신. 실행 중인 Qwen overlay와 기본 Melo 구성을 구분한다.

## 선정 결과

- 공급자: 온라인은 로컬 서버. 기본 Compose는 MeloTTS, Qwen overlay는 Qwen3-TTS를 사용한다.
- 음성: Qwen은 설명 기반 여자아이·남자아이 두 합성 참조 중 선택한다. 오프라인은 기존 기기 음성/고정 WAV 대체 경로이며 같은 음색을 보장하지 않는다.
- 비용: 외부 TTS API를 호출하지 않으므로 별도 사용료가 없다.
- 적용 범위: 카드 단어, 생성 문장, 설정 미리 듣기에 동일한 설정을 사용한다.
- 저장: 프리셋, 기기 음성 이름, 속도, 음높이 및 기본 볼륨을 MongoDB에 사용자별로 저장한다.
- 측정: 발화 원문 없이 콘텐츠 종류, 성공 여부, 오류 코드와 발화 시작 지연 시간만 저장한다.
- 집계: 운영 계정은 [TTS 지표](../development/OPERATIONS_METRICS.md#tts-metrics)에서 기존 클라이언트 보고의 시작 지연·실패율을 조회한다. 취소·결과 미수신을 실패로 간주하지 않고 중복 요청 ID의 최초 결과를 보존한다.

## 음성 프리셋

| 프리셋 | 기본 속도 | 기본 음높이 |
|---|---:|---:|
| 여자아이 | 0.90 | 1.25 (기기 대체 경로만) |
| 남자아이 | 0.90 | 1.15 (기기 대체 경로만) |

Qwen 서버 음색은 별도의 합성 참조로 결정한다. 실제 아동 성우/연령을 보장하지 않는다.
일반 UI의 목소리 선택은 두 가지만 제공하고 기기 음성 목록·음높이 수동 선택은 제거한다.
이전 child/woman 설정은 girl, man 설정은 boy로 읽으며 저장 시에도 정규화한다.
기존 기기 음성 이름과 pitch 필드는 이전 설정 호환용으로 유지한다.

## 캐시

- 브라우저: 세션별 30분, 최대 128개/64MiB. 로그아웃·세션 변경 시 초기화한다.
- backend 메모리: 계정별 키, 30분, 전체 최대 256개/64MiB. 프로세스 재시작 시 사라진다.
- Qwen 공개 카드 디스크 캐시: 기본 제공 카탈로그의 정확한 label만 허용한다.
  개인 카드나 임의 생성 문장은 별도 디스크 캐시에 넣지 않고 위 메모리 경로만 사용한다.
  기본 카드와 동일한 공개 문구는 공유할 수 있지만 사용자 ID·사용 이력·원문 메타데이터는 파일에 넣지 않는다.
- 디스크 키는 공급자·주소·음색 버전·girl/boy·문구·속도의 해시이며 WAV만 저장한다.
  Docker `public_speech_cache` 볼륨에 최대 512개/128MiB, 생성 후 7일을 적용한다.
  만료는 조회 시 거부·해당 파일 삭제, 저장 시 만료/오래된 파일 정리로 적용하며 주기 삭제 작업은 아니다.
- 디스크 오류/손상은 캐시 미스로 처리해 다시 합성하고, 실패 응답은 저장하지 않는다.
  사용자 데이터 삭제 후에도 공개 고정 문구 캐시는 남을 수 있다. 개인 음성 저장 기능이 아니다.
- 최초 캐시 미스는 모델 합성이 필요하다. 모든 카드를 미리 합성하지 않으며 첫 사용 지연은 남는다.

## 장애 및 대체 방식

1. 온라인 Qwen은 선택 음색의 캐시/서버 WAV를 우선한다. 존재하지 않는 음색 요청은 다른 음색으로 몰래 대체하지 않는다.
2. 오프라인에서 고정 WAV 또는 기기의 한국어 음성을 사용한다. 기기 음색은 운영체제에 따라 다르다.
3. 서버 합성 실패는 성공으로 처리하지 않는다. 카드·문장을 유지하고 오류와 재시도를 제공한다.
4. 캐시 성공을 실제 스피커 재생 성공으로 보지 않는다. iPad 권한·음량·장시간 부하는 별도 실기 검수 대상이다.

## 기본 표현 사전 음성

- 범위: 기본 빠른 표현 5개와 복구 표현 8개. 사용자 입력 문장, 개인 카드 문구와 녹음은 포함하지 않는다.
- 자산: `frontend/public/audio/core/v1/manifest.json`과 16kHz·16bit·mono PCM WAV 13개, 합계 약 800KB.
- 생성: Windows의 `Microsoft Heami Desktop` 음성으로 `scripts/generate-core-speech.ps1`을 실행한다. 스크립트는 `App.jsx`의 기본 표현 목록을 읽고 WAV 형식과 크기를 검사한다. 사용자 발화를 외부 TTS로 전송하지 않는다.
- 준비: AAC 사용자 로그인 직후 비동기로 내려받아 IndexedDB `coreSpeech`에 저장한다. 로그인·카드 조회 완료를 기다리게 하거나 자동 재생하지 않는다.
- 실패: 일부 다운로드나 저장 공간 부족 시 재생 가능한 파일은 유지하고 실제 저장 개수를 표시한다. 다시 준비하면 누락 파일만 요청한다. 오프라인 복원 도중 재연결되어도 누락 파일을 준비한다.
- 재생 설정: 사전 음성은 속도와 볼륨을 적용하며 기기 음성 선택·음높이는 적용하지 않는다. 현재 미리 듣기는 온라인 서버 경로를 사용한다.
- 삭제: 공용 고정 문구만 저장하므로 로그아웃·사용자 데이터 삭제 뒤에도 재사용한다. 사이트 데이터 삭제 시 제거된다. 사용자별 기록·스냅샷 삭제 정책은 유지한다.
- 교체: 문구나 음성을 변경하면 자산 경로·manifest·`CORE_SPEECH_VERSION`을 함께 올린다. 구버전 묶음은 읽지 않고 새 묶음 저장 시 교체한다.
- 검증 한계: 생성 도구와 음성 자산의 외부 배포 사용 조건은 운영 배포 전 라이선스 검토 항목에 포함한다. 자동 테스트 통과만으로 실기 지원을 선언하지 않는다.
