# 말하기 카드 탭과 폴더

> 후속 변경: [대표 그림과 통합 격자](SYMBOL_FOLDER_COVERS.md)를 적용했다.
> 카드의 별·개별 듣기는 `카드 도구`를 펼쳐 사용하며, 홈 카드와 폴더를 같은 격자로 표시한다.

## 화면 구성

- `무엇을 말하고 싶나요?` 대신 홈·즐겨찾기·긴급어·감정·시간/일정 분류를 표시한다.
- 홈의 기본 카드는 좋아요·싫어요·도와주세요 순서다. 실제 사용 가능한 카드만 표시한다.
- 나머지는 기존 카드 분류와 보호자가 저장한 상황 카드판을 그림 미리보기가 있는
  폴더로 표시한다. 기본 카드판·모든 카드·다시 말하기 폴더도 제공한다.
- 폴더를 열면 관련 카드가 표시되고 목록으로 돌아올 때 해당 폴더로 초점을 복귀한다.
  기본·상황 카드판 폴더에서는 저장된 슬롯 순서를 따른다.
- 현재 카드판 표시·말하기 상세설정·기존 카테고리 버튼 열을 제거했다.
  말하기 화면의 중복 빠른 표현 목록은 홈 카드와 긴급어로, 복구 표현은
  다시 말하기 폴더로 접근한다. 다른 화면의 빠른 표현은 유지한다.
- 이전 문장·다시 듣기와 추천은 유지하며 카드 목록 뒤에 배치한다.

## 데이터와 동작

- 긴급어는 `safety_relevant`, 감정은 기존 감정 분류와 semantic_group을 사용한다.
  시간/일정은 시간·일정·날짜 분류 또는 관련 semantic_group을 사용한다.
  해당 카드가 없으면 빈 상태이며 새 단어·가짜 그림을 생성하거나 DB에 등록하지 않는다.
- 검색은 홈에서 사용 가능한 전체 카드, 나머지 탭·폴더에서는 해당 범위에 적용한다.
  사용자별 카드 수/페이지 설정과 카드 크기 설정을 유지한다.
- 선택 카드는 기존 발화 모드에 따라 문장 담기 또는 단어 발화를 한다.
  복구 표현은 기존대로 직접 발화하며 문장 생성에 잘못된 카드 ID를 넣지 않는다.
- 카드 ID·원본 사진·권한·카드판 설정·잠금 데이터는 수정하지 않는다.
  새 탭·폴더는 탐색용이며 기존 단일 카드판 화면의 고정 위치를 그대로 보여 주는
  모드는 아니다. 카드판 폴더 내부만 저장된 순서를 따른다.
- 기록 상황 상세 선택 UI를 제거했으며 폴더 이동을 기록 상황으로 추정하지 않는다.

## 즐겨찾기

- 카드의 별로 직접 추가·해제한다. 현재 기기 브라우저에 계정 ID별로 저장한다.
  서버 동기화나 다른 기기 공유는 제공하지 않는다.
- 동의 없는 기록 비저장 모드에서는 메모리에서만 유지하며 화면을 떠나면 초기화한다.
- 실제 사용 가능한 카드 ID만 표시하므로 삭제·권한 소멸 카드는 나오지 않는다.
- 로컬 데이터 삭제 함수에서 즐겨찾기 키도 제거한다. 저장 실패 시 현재 화면에서
  계속 사용하고 저장하지 못했다는 안내를 표시한다.

## 검증 기록

- 최종 프런트엔드 빌드와 변경분 공백 검사 통과. 기존 500kB 초과 청크 경고는 유지된다.
- 실제 분리 Chrome 데모 계정에서 탭 5개와 홈 3장의 정확한 순서, 폴더 목록,
  기본 카드판 폴더의 카드 표시, 열기/돌아오기 초점, 긴급어 9장·감정 9장과
  시간/일정 빈 상태를 확인했다.
- 별로 좋아요를 지정하고 즐겨찾기 탭 표시 및 새로고침 후 복원을 확인했다.
  검수 전 로컬 즐겨찾기로 복구했고 DB 카드·설정·발화·사용 기록은 저장하지 않았다.
- 320·390·768·1280px에서 탭 5개와 홈 3장을 유지하고 페이지 가로 넘침이 없었다.
  390/1280px를 캡처하고 390px 화면을 시각 확인했다. 캡처는 커밋하지 않는다.
- 초기 로드와 탭 전환이 겹쳐 두 번의 브라우저 검수가 중단됐다.
  로드 안정 후 다시 실행해 위 확인을 완료했다. 임시 로그인은 로그아웃하고 브라우저를 종료했다.
- 실제 발화·RFID·문장 생성·사용자별 오프라인·동의 철회·삭제·저장 실패·
  다른 계정 격리·페이지 넘기기·실기기·스크린리더 전수 검수는 미실행이다.
- 사용자 카드 PNG·PDF와 수정 중인 제작 체크리스트는 변경하거나 커밋하지 않는다.
