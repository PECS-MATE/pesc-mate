# 보호자 설정과 기록 없는 기본 사용

2026-10-24 사용자 요청: 아동의 개인정보 화면 강제 이동을 없애고 보호자 설정으로 분리한다.
동의가 없어도 카드 탐색·선택 카드 발화·긴급/복구 표현을 사용할 수 있다. 동의는 자동으로
체크하거나 서버에 대신 저장하지 않는다.

## 반복 화면의 코드상 원인

기존 온라인·오프라인 로딩은 `guardian_consent`가 false/없는 경우 항상 개인정보 탭으로
이동했다. 이미 저장된 true 동의를 매 로그인 초기화하는 코드는 아니다. 화면에서 체크만
하고 **동의 및 기간 저장**을 누르지 않은 경우도 서버 값은 false다. 특정 사용자 DB의 실제
반복 원인은 조회하지 않았으며 테스트를 사용자 DB에서 실행하지 않는다.

## 변경한 흐름

- 아동 주 메뉴에서 개인정보 버튼을 빼고 보호자 설정으로 옮긴다.
  2026-10-28부터 **이름·프로필 사진 → 마이페이지 → 보호자 설정**에서 관리한다.
  자세한 화면 구성은 [마이페이지 안내](MY_PAGE_SETTINGS.md)를 따른다.
  기본 말하기는 동의 화면으로 강제 이동하지 않는다. 저장된 동의는 이후 로그인에도 유지한다.
- 이 영역은 화면상의 관리 구분이다. 새 보호자 인증/PIN·법정대리인 신원 확인이나 연결된
  보호자 계정의 새로운 개인정보 쓰기 권한을 구현한 것으로 취급하지 않는다. 기존 계정
  소유자의 API 권한은 유지한다.
- 동의 편집 초안과 서버에서 확인된 동의를 분리한다. 체크만 바꿔도 수집이 켜지던 로컬
  상태 혼동을 막고, 서버 저장에 성공한 뒤에만 확정 값을 사용한다. 오프라인 저장은 막는다.
- 동의가 없으면 새 선택·발화 이력, 추천 노출/선택, AI 문장 생성/저장, 선택 카드의
  localStorage 초안, 학습 진행/완료 결과와 새 오프라인 기록을 저장·전송하지 않는다.
  문장 조합은 선택 카드 그대로 기기 음성으로 말한다. 연습 결과는 현재 화면에서만 본다.
- 동의가 없을 때 새로 읽는 카드/설정 스냅샷에도 false 상태를 유지하므로 캐시 복원 뒤
  동의 화면으로 보내거나 기록 수집을 켜지 않는다. 기존 동의 때 만든 대기 이력은 임의로
  삭제하지 않고, 동의가 없을 때 자동 동기화하지 않는다. 기기 TTS의 온라인/오프라인
  지원 한계는 기존 음성 정책과 같다.

이는 모든 계정 데이터·프로필·기존 서버 이력을 없애는 익명 모드가 아니다. 로그인 세션,
기존 사용자별 카드/설정 캐시와 기본 음성은 기존 범위로 남는다. 서버 이력/사진 삭제는
별도 명시적 개인정보 삭제를 사용한다. 서버의 동의 없는 문장·발화·학습·이미지 쓰기
거절은 제거하지 않았다. 실제 동의 고지·신원/정책 버전·법적 승인은 별도다.

## 검증 기록

Node 96·React 174개, 총 270개와 빌드 통과. 새 App 검사 3개는 동의 전·미저장 초안·
오프라인 사용에서 기록 API와 기기 선택 초안이 생성되지 않는지 확인했다.
초기 소스 검사와 아이콘을 포함한 버튼 선택자 오류는 수정했다. 동시 브라우저 실행 중
기존 12장 한도 검사 1개가 5초 시간 초과됐으나, 브라우저 종료 후 같은 소스·같은 제한으로
전체 단독 재실행이 통과했다. 시간 제한이나 검사 개수는 완화하지 않았다.

Chromium 7개 통과: 동의 전·체크만 한 상태·오프라인 새로고침·기기 음성·명시 저장 후
재로그인·기존 지원 기록과 개인정보 삭제를 실제 API/임시 MongoDB로 확인했다.
`.local-validation/learning-guardian-20261024/browser-guardian/report/`에 보고서를 남겼고
임시 스택은 정리했다. 백엔드 코드는 변경하지 않았으며 사용자 DB·동의·사진은 수정하지 않았다.
실제 태블릿·법정대리인 절차 검수와 전체 `verify:full`은 이 단위에서 미실행이다.
