# PESC MATE 카드 사진·단어 목록

> 작성일: 2026-10-10
> 이미지 현황 갱신: 2026-10-26
> 목적: 현장 파일럿에 필요한 기본 카드와 아동별 사진 촬영 목록을 정하고, 이후 확장 카드를 우선순위별로 관리한다.

## 1. 사용 원칙

- 모든 카드를 한 화면에 노출하지 않는다.
- 전체 카드 라이브러리와 아동의 고정 카드판을 구분한다.
- 첫 고정 카드판은 아동이 기존에 쓰던 실물 카드와 보호자·담당자의 평가를 기준으로 12~20장부터 시작한다.
- 빠른 표현은 최대 5~8개, 복구 표현은 최대 4개를 고정 위치에 둔다.
- 기본 제공 카드는 같은 그림체의 상징 그림을 사용하고, 개인화 단계에서는 사람·실제 장소·선호 음식·개인 물건을 아동에게 익숙한 실제 사진으로 교체할 수 있다.
- 행동, 감정, 거절, 질문, 시간처럼 사진 한 장으로 의미가 모호한 단어는 일관된 상징 그림을 사용한다.
- 단어 카드에는 한 가지 개념만 담고 이미지 안에 글자를 합성하지 않는다. 글자는 UI에서 별도로 표시한다.
- 같은 의미의 카드 이미지를 자주 바꾸지 않는다.
- 개인 사진은 공용 카드로 전환하지 않고 촬영 동의와 삭제 대상을 기록한다.
- 기본 제공 카드는 모두 동일한 상징 그림 스타일로 제작한다.
- 사용자가 올린 사진은 기본 이미지를 덮어쓰지 않는 사용자별 대체 이미지로 저장한다.
- 이미지 교체 후에도 카드 ID, 표시 단어, 뜻, TTS, 카드 위치와 사용 기록은 유지한다.
- 보호자 또는 권한 있는 담당자가 언제든 기본 이미지로 되돌릴 수 있게 한다.

#### 8종 공통 시각 스타일

- 정사각형 1:1 구도, 권장 원본 1024×1024px
- 흰색 또는 매우 연한 단색 배경
- 피사체는 화면 중앙의 약 65~75% 크기
- 둥글고 선명한 외곽선과 단순한 색면
- 그림자는 약하게 사용하고 복잡한 질감과 배경 사물은 제외
- 행동 카드에는 같은 연령대·같은 복장 계열의 인물 사용
- 성별을 지나치게 강조하지 않는 중립적인 인물 표현
- 카드 이미지 안에는 단어, 문장, 로고, 워터마크를 넣지 않음
- 색만으로 의미를 전달하지 않고 자세·사물·방향으로 의미를 전달
- 축소된 카드에서도 핵심 동작이나 물건을 구분할 수 있도록 제작

#### 대체 텍스트 적용 기준

- 화면에 보이는 표시 단어와 대체 텍스트를 똑같이 반복하지 않는다.
- 표시 단어는 카드의 의사소통 의미를 전달하고, 대체 텍스트는 그림에 무엇이 보이는지 짧게 설명한다.
- 장식 요소, 배경색, 그림체는 의미 구분에 필요할 때만 대체 텍스트에 포함한다.
- 버튼의 접근 가능한 이름은 `{표시 단어} 카드`로 제공하고, 이미지 대체 텍스트는 위 표의 문구를 사용한다.
- 이미지가 버튼 안에서 장식 역할만 한다면 중복 낭독을 막기 위해 이미지 자체는 빈 대체 텍스트로 처리하고 버튼 이름에 표시 단어를 제공한다.

### 3.4 나머지 필수 카드 제작 상세 가이드

## 4. 이미지 제작 규격

### 공통 규격

- 권장 원본: 정사각형 1024×1024px 이상
- 서비스 저장 형식: WebP
- 피사체: 한 카드에 한 개념, 중앙 배치
- 배경: 단색 또는 시각적으로 단순한 실제 배경
- 여백: 카드 가장자리에서 피사체가 잘리지 않도록 10% 이상
- 문자: 이미지 안에 삽입하지 않음
- 로고·상표: 가능하면 제거
- 촬영 정보: EXIF 위치·기기 정보 제거
- 파일명: 영문 카드 ID 또는 `사용자ID_분류_순번`
- 대체 텍스트: 카드 표시 단어와 의미가 일치하도록 작성

### 이미지 방식 선택

| 대상 | 권장 방식 | 이유 |

| 가족·친구·선생님·담당자 | 기본 사람 상징 그림, 이후 동의받은 개인 사진 | 기본 세트의 일관성을 유지하고 개인화 시 실제 인물 식별 지원 |

## 6. C1 — 아동별 초기 사진 촬영 목록

아래 목록은 공용 이미지가 아니라 각 아동의 생활환경을 촬영해 개인 카드로 등록한다. 모든 항목을 의무로 촬영하지 않고 실제 사용하는 대상만 선택한다.

### 6.1 사람

## 12. 카드 등록 체크리스트

- [ ] 카드 ID가 중복되지 않는다.
- [ ] 표시 단어와 의미 설명이 일치한다.
- [ ] 품사와 문장 역할이 지정되어 있다.
- [ ] 같은 발음의 다른 뜻을 이미지와 의미로 구분한다.
- [ ] 이미지가 한 가지 개념을 명확히 보여 준다.
- [ ] 개인 사진의 동의와 공개 범위가 확인되었다.
- [ ] 공용 이미지의 저작권·배포 권한이 확인되었다.
- [ ] 이미지의 EXIF와 불필요한 개인정보가 제거되었다.
- [ ] 카드의 TTS 발음이 실제 기기에서 확인되었다.
- [ ] 오프라인 상태에서 이미지와 핵심 음성이 표시된다.
- [ ] 고정 카드판에 추가할지 라이브러리에만 둘지 결정되었다.
- [ ] 보호자 또는 권한 있는 담당자가 최종 위치를 확인했다.
