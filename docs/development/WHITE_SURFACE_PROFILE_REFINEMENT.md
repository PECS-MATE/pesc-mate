# 흰색 페이지 배경과 원형 프로필 정리

## 원인과 변경

- 랜딩의 `section`은 경계·그림자·모서리만 초기화하고 배경은 초기화하지 않아
  공통 `section`의 민트색을 상속받았다. 고정 콘텐츠 폭의 첫 영역만 사각형으로
  칠해져 양옆 크림색 페이지와 분리돼 보였다.
- 랜딩 section의 배경을 명시적으로 투명화하고, 전체 페이지 배경 토큰은 흰색
  표면 토큰의 별칭으로 변경했다. 헤더·첫 영역·소개 영역이 동일한 흰 배경으로
  이어지며 제목·간격·구분선으로 영역을 나눈다.
- 공통 section 기본값과 문장판·로그인 화면의 장식용 배경도 흰색으로 정리했다.
  랜딩 예시 배지·문장·보호자 안내는 흰색과 구분선을 사용한다.
  실제 선택·주요 행동·오류·성공·경고·키보드 포커스 색상 토큰은 유지한다.
- 프로필 아바타는 흰 바탕·원형 윤곽선으로 표시하고 그림자를 제거한다.
  열린 내 계정 상태는 원형 선을 강조하며 사이드바의 프로필 버튼 전체를
  민트색 사각형으로 채우지 않는다.
- 프로필 선택에서는 사각 라벨의 색 배경·테두리를 제거하고 이미지의 원형 선으로
  선택을 표현한다. 선택한 이미지는 3px 선, 기본은 1px 선을 사용한다.
  라디오 입력·이름·키보드 초점과 기존 저장 동작을 유지한다.
- 원본 카드·프로필·사용자 사진은 수정하지 않는다. 사진 자체에 포함된 색이나
  장식은 CSS로 제거하거나 이미지 보정을 하지 않는다.

## 확인 결과

- 실제 임시 Chrome에서 랜딩·보호자 프로필을 1440/390px로 캡처했다.
  페이지 배경은 `rgb(255,255,255)`, 랜딩 첫 영역·소개 영역은 투명으로 확인했다.
  두 화면 폭에서 페이지 전체 가로 넘침이 없었다.
- 프로필 이미지 모서리 50%, 선택된 원형 선 3px, 열린 내 계정 아바타 선 2px,
  사이드바 프로필 배경 흰색을 확인했다. 원본 사진·프로필 저장은 수행하지 않았다.
- CSS 3개 정적 구문 검사와 변경분 공백 검사, 프런트엔드 빌드를 통과했다.
  기존 500kB 초과 JS 청크 경고는 남아 있으며 이번 배경 변경의 범위가 아니다.
- 실제 기기·전체 아동/담당자 화면·모든 접근성 상태의 전수 검수는 미실행이다.
  프로필 변경 저장·사진 업로드도 미실행이며 시각적 표시 확인과 구분한다.
- 사용자가 추가한 PNG·캡처·빌드 결과물은 커밋에서 제외한다.
  검수용 로그인은 로그아웃하고 분리 실행한 브라우저만 종료한다.
