## 추가 재현이 필요한 항목

### 일반 사용자 로딩의 세션 교체 경계

`frontend/src/hooks/use-offline-session.js`의 `load`는 지원 사용자 분기에서
세션을 재확인하지만 일반 사용자 분기에서는 `Promise.all`과 이미지 로딩 후
화면 상태·캐시 적용 직전의 세션 확인이 없다. 이전 코드에서 유지된 경계다.

이번 QA에서는 로그아웃/계정 교체 중 지연 응답을 화면에서 재현하지 못했으므로
확정 결함으로 판정하지 않는다. 후속 재현은 계정 A의 로딩을 지연하고 로그아웃
또는 계정 B 로그인 후 응답을 완료하여 화면과 IndexedDB가 덮어써지는지 확인한다.
재현된다면 각 비동기 경계 뒤 `if (!isCurrentSession()) return;`을 적용하고,
오래된 응답에서 만든 object URL도 회수하는 방향으로 수정한다.

### 설정 화면 분리의 실제 사용자 조작

`frontend/src/components/account-settings-panel.jsx`의 역할별 섹션 노출·저장·
동의/연결 변경·이동 후 닫힘·Escape·포커스 복귀는 기존 자동 테스트 통과만으로
확인되지 않는다. Aside 연결 후 사용자·보호자·지원/운영 역할의 설정 흐름을
별도 확인해야 한다. 현재는 미검증이며 정상 또는 결함으로 단정하지 않는다.
