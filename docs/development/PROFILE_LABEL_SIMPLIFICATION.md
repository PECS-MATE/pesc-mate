# 사이드바 프로필 문구 단순화

- 모든 역할이 공유하는 프로필 버튼에서 AAC 사용자·보호자 계정·담당자 계정
  안내와 `마이페이지 · 설정` 문구를 제거했다.
- 프로필 이미지·이름·톱니바퀴와 기존 마이페이지 열기 동작은 유지한다.
- 버튼의 접근성 이름, 펼침 상태, 현재 페이지 표시와 키보드 동작은 유지한다.
- 권한 판정·가입 안내·마이페이지 내부 제목은 변경하지 않는다.
- 사용하지 않는 프로필 보조 문구 CSS를 제거했다.

## 검증

- 프런트엔드 프로덕션 빌드 통과. 기존 500kB 초과 청크 경고는 남아 있다.
- 변경분 공백 검사 통과.
- 역할별 실제 로그인·화면 크기별 브라우저·스크린리더 검수는 미실행이다.
- 사용자가 추가한 카드 사진과 빌드 결과는 커밋에 포함하지 않는다.
