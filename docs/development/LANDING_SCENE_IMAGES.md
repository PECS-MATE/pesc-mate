# 랜딩 사용 장면 이미지

- `assets/main/태그이미지.png`를 랜딩 상단 카드 태그 소개에 사용한다.
- `assets/main/aac사용.png`를 태블릿 AAC 사용 소개에 사용한다.
- 두 이미지의 전체 구도를 유지하고 컨테이너 너비에 맞춰 축소한다.
- 이미지 크기 속성으로 로딩 공간을 확보하고 아래 이미지는 지연 로딩한다.
- 대체 텍스트와 사용 장면 예시 캡션을 제공한다. 실제 서비스 화면이라는 표현을 쓰지 않는다.
- 더 이상 쓰지 않는 이미지 자리 표시 컴포넌트와 스타일을 제거한다.
- 이번 요청의 두 main 이미지만 커밋한다. 나머지 카드·마스코트 원본은 포함하지 않는다.

## 검증

- 원본 이미지 두 장의 내용 및 크기 확인 완료.
- 프런트엔드 빌드·공백 검사 통과. 기존 500kB 청크 경고는 유지된다.
- 실제 브라우저의 모바일·데스크톱 시각 검수는 미실행이다.
