# 문장판 상시 설명 제거

- `카드 고르기 → 내용 확인 → 말하기`, 빈 문장판 안내, 단어 모드 안내와
  자동 생성 대기 중의 사용법 문구를 제거했다.
- 카드 이동 안내는 화면에서 숨기되 스크린리더 설명으로 유지한다.
- 생성 작업이나 결과가 없을 때 빈 자동 문장 박스를 표시하지 않는다.
- 제목·도구·선택 카드·완성 문장을 중심으로 표시한다. 생성 중은 짧은
  상태 문구로 표시하고 실패 안내·대체 발화는 유지한다.
- 접힌 생성 정보 상세 보기와 기존 발화·생성·카드 이동 동작은 유지한다.

## 검증

- 프런트엔드 빌드와 변경분 공백 검사 통과.
- 기존 500kB 초과 청크 경고는 남아 있다.
- 실제 브라우저·실기기의 빈 상태·카드 이동·생성·발화·스크린리더 검수는
  미실행이다. 사진과 빌드 결과물은 커밋에서 제외한다.
