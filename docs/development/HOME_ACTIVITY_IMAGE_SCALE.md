# 홈 활동 그림 배율 조정

- 말하기·연습하기 대표 그림을 공통 미니 카드 스타일에서 분리한다.
- 그림 영역을 데스크톱 88px, 작은 화면 64px 정사각형으로 키운다.
- 모바일 첫 열 너비도 함께 늘려 그림이 잘리거나 제목과 겹치지 않게 한다.
- 원본은 contain으로 표시하며 비율 유지, 반복 방지, 흰 배경과 일정한 안쪽 여백을 적용한다.
- 작은 그림에 중첩되던 테두리와 그림자는 제거하고 버튼 전체의 형태는 유지한다.
- 기존 카드 순서에 따른 대표 카드 선정과 다른 카드 화면의 크기는 변경하지 않는다.

## 검증

- 프런트엔드 빌드와 공백 검사 통과. 기존 500kB 청크 경고는 유지된다.
- 실제 브라우저의 화면별 배율·시각 검수는 미실행이다.
