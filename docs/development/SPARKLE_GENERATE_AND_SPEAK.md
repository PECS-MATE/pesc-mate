# 반짝이 버튼으로 문장 생성 후 바로 발화

- 반짝이를 누르면 기존 문장 생성 API를 호출하고 성공 결과를 즉시 TTS로
  전달한다. 이미 생성한 문장이 있으면 재생성 API 결과를 발화한다.
- 카드 선택만으로 실행하던 700ms 자동 생성은 제거했다. 버튼을 누르기 전에
  요청이 시작되어 버튼이 비활성화되거나 불필요하게 재생성하는 것을 피한다.
- 아래의 결과 박스·생성 정보·별도 문장 발화 버튼을 제거했다.
- 스피커는 기존대로 선택 카드 그대로 말하기이다. 기록 동의·오프라인·
  중복 요청 제한과 생성 실패·음성 실패 안내 및 재생 제어를 유지한다.
- 생성 결과는 기존 백엔드 모델/대체 생성 정책을 따른다. 모델 장애 시에도
  반드시 모델 결과라고 보장하지 않으며 이번 변경은 모델 설정을 바꾸지 않는다.
- 카드·화면·계정·동의가 바뀐 요청은 기존 컨텍스트 확인으로 버린다.
  요청 이후 다른 음성이 시작되거나 중지했다면 뒤늦은 결과를 자동 발화하지 않는다.
- 새 결과의 세션 ID를 발화 기록에 직접 전달해 React 상태 반영 전에도
  직전 세션과 혼동하지 않도록 했다. 화면 전용 출처·횟수·확인 상태를 정리했다.

## 검증

- 프런트엔드 빌드와 변경분 공백 검사 통과.
- 기존 500kB 초과 청크 경고는 남아 있다.
- 실제 모델·생성 API·TTS·지연 응답 취소·동의/오프라인·기기별 브라우저
  회귀 검수는 미실행이다. 빌드 성공을 기능 검증 완료로 보지 않는다.
- 사용자 카드 사진과 빌드 결과물은 커밋에서 제외한다.
