# PECS Mate 카드 제작 체크리스트

> 확인일: 2026-11-01 · 총 41종 · 로컬 작업 폴더 기준
> 제작 규격·복사용 프롬프트: [카드 이미지 제작 가이드](CARD_IMAGE_PRODUCTION_GUIDE.md)

## 현재 진행 상황

| 단계 | 확인된 수 | 의미 |
| --- | --- | --- |
| 파일 준비 | 1/41 | 작업 폴더에서 해당 이름의 PNG 확인. 초안도 포함 |
| 규격·의미 검수 | 0/41 | 형식·크기·용량·구도·의미·그림체 확인 완료 |
| 웹·실물 확인 | 0/41 | 실제 표시·선택·TTS와 적용 대상인 RFID·출력 확인 |

현재 `frontend/src/assets/cards/나.png`만 로컬에 있으며 Git에는 아직 추가되지 않았다.
이 문서 커밋에는 사용자가 추가한 이미지를 포함하지 않는다.
나머지 40종은 이 폴더에서 확인되지 않았다. Gemini나 다른 폴더에서 이미 생성했는지는
알 수 없으므로, 미체크를 “어디에서도 제작하지 않음”으로 해석하지 않는다.

### 체크 방법

- **파일 준비**: 최종 파일명으로 카드 폴더에 두었을 때 체크한다. 그림 품질 승인과는 다르다.
- **규격·의미 검수**: PNG 형식·여백·권장 해상도/용량·표현 의미를 사람이 확인한 뒤 체크한다.
- **웹·실물 확인**: 실제 웹 화면과 적용 대상인 출력물·RFID에서 확인한 뒤 체크한다.
  실물 제작 대상이 아니라면 해당 항목 옆에 “실물 해당 없음, 웹 확인 완료”와 확인일을 기록한다.
- 새 파일을 넣거나 수정한 뒤 수동으로 상태와 위 집계를 갱신한다. 파일명은 공백을 `_`로 바꾼다.
- 제작 순서는 개발 작업용이며 아동 교육 순서나 임상 단계가 아니다.

### 나 카드 확인 메모

- PNG 시그니처·헤더상 2048×2048px, 3,189,873바이트(약 3.04MiB).
- 1024×1024px·1MiB 이하 권장값과 차이가 있으므로 납품본 조정 여부를 검토한다.
  현재 파일을 임의로 축소하거나 수정하지 않았다.
- 성별 단서를 줄인 자기 지시 표현인지, “남자아이”가 아닌 “나”로 이해되는지는 검수 대기다.
- 전체 디코딩·그림 내용·브라우저·실기기 검증은 하지 않았다.

## 공통 검수 기준

- [ ] 마스코트 없이 사물 사진형과 사람 그림상징을 구분했다.
- [ ] 기본 배경은 흰색이고 글자·로고·워터마크·카드 테두리가 없다.
- [ ] 정사각형·여백·용량·확장자뿐 아니라 실제 파일 형식도 확인했다.
- [ ] 나·일반 행동 인물에서 불필요한 성별 단서를 줄였다.
- [ ] 사물 사진형은 고유색을 유지하고, 사람 그림끼리는 선·피부색·단순화 정도를 맞췄다.
- [ ] 물/마시다, 밥/먹다, 손/그만, 좋아요/네/맞아요 등 혼동 가능성을 비교했다.
- [ ] 얼굴 전체·전신은 필요한 경우에만 넣고 손·입·도구의 접촉과 방향은 유지했다.
- [ ] 보호자·담당자가 사용자가 이해하는 의미인지 확인했다.
- [ ] 작은 카드·빠른 표현·확대 화면에서 잘림과 식별성을 확인했다.
- [ ] 이미지 교체 후 카드 ID·위치·발화·RFID 매핑이 유지되는지 확인했다.

이 공통 목록은 전체 세트에 대한 별도 확인 항목이며 카드별 검수 개수를 자동으로 바꾸지 않는다.
“너”·“주세요” 등 현재 기본 목록 밖의 어휘는 별도 확장 범위로 관리한다.

## 이번 문서 작업의 검증 기록

- 제작 가이드의 41개 파일명과 중복·누락 없이 일치하는지 정적으로 대조했다.
- 로컬 PNG 존재 상태와 파일 준비 체크, 단계별 집계·로컬 링크·`git diff --check`를 확인했다.
- 최초 스테이징 공백 검사에서 문서 끝의 빈 줄을 발견해 제거했고 재검사를 통과했다.
- 사용자 제공 `나.png`의 바이트·PNG 시그니처·헤더만 읽었고 파일은 수정하지 않았다.
- 이미지 생성·수정·전체 디코딩·자동 테스트·빌드·브라우저·실기기·사용자 검증은 미실행이다.

## 이미지 원본 커밋 기록 — 2026-11-02

- 사용자 요청에 따라 미커밋 카드 PNG 40장과 main 마스코트 PNG 1장을 추가한다.
- 기존 체크리스트 수정과 이미지 원본을 그대로 보관하며 제작·의미 검수를 완료 처리하지 않는다.
- 파일 목록과 스테이징 공백 검사를 확인한다. 이미지 수정·전체 디코딩·빌드 재실행·
  브라우저·실기기 검수는 이번 이미지 커밋에서 미실행이다.
