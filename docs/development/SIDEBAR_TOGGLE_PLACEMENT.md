# 메뉴 펼침·접기 아이콘 위치 정리

## 변경

- 메뉴 아이콘의 상시 테두리·색 배경·그림자·둥근 박스를 제거했다.
  조작 영역은 44px이며 키보드 초점 윤곽은 유지한다.
- 펼쳤을 때는 브랜드와 같은 행의 오른쪽 끝에 접기 아이콘을 표시한다.
  본문에는 중복 버튼을 표시하지 않는다. 접으면 본문 왼쪽 위의 펼치기
  버튼으로 초점을 돌려준다.
- 1000px 이하 메뉴는 위쪽 두 열 배치에서 왼쪽 패널로 변경했다.
  작은 화면에서도 브랜드와 오른쪽 접기 버튼을 표시하고 메뉴 항목은 한 열이다.
- 작은 화면의 패널은 바깥 영역 클릭·Escape·메뉴 선택·프로필 선택으로 닫힌다.
  열려 있는 동안 본문은 inert, 배경 스크롤은 잠금, Tab 초점은 패널 안에서
  순환한다. 닫거나 큰 화면으로 전환하면 잠금을 해제한다.
- 보호자 테마의 일반 버튼 흰 배경 규칙보다 아이콘의 투명 배경이 우선하도록 했다.

## 검증

- 최종 프런트엔드 빌드와 변경분 공백 검사 통과.
  기존 500kB 초과 청크 경고는 남아 있다.
- 최초 검수에서 초기 초점이 패널에 들어가지 않는 경우와 보호자 흰 배경을
  발견해 수정했다. 로드 전 DOM 접근으로 중단된 검수도 앱 준비 대기로 수정 후 재실행했다.
- 실제 분리 Chrome에서 아동·보호자 각각 320·390·1000·1280px 확인:
  메뉴가 왼쪽에서 열리고, 아이콘은 브랜드 행 오른쪽 끝이며 border 0px·
  투명 배경이고 페이지 가로 넘침이 없었다.
- 1000px 이하에서 열릴 때 접기 버튼 초점, 본문 inert, Escape 닫기와
  펼치기 버튼으로의 초점 복귀를 확인했다. 390px에서 마지막 버튼 다음 Tab이
  접기 버튼으로 순환하는 것도 두 계정에서 확인했다.
- 1280px에서는 일반 사이드바를 유지하고 접기 및 초점 복귀를 확인했다.
  처음부터 펼쳐진 데스크톱 화면에 강제로 초점을 이동시키지는 않는다.
- 검수용 로그인은 로그아웃하고 분리 브라우저를 종료했다. 카드·설정은 저장하지 않았다.
- 바깥 클릭·메뉴 선택 자동 닫힘·실제 실기기 터치·Shift+Tab·스크린리더·
  모든 역할과 화면·USB·TTS 전수 검수는 미실행이다.
- 사용자 카드 PNG와 수정 중인 제작 체크리스트는 변경·커밋하지 않는다.
