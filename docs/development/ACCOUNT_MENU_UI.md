# 계정 메뉴와 프로필 팝업

- 사이드바의 사진·이름은 표시하고 톱니바퀴 버튼으로 ‘프로필·로그아웃’ 두 항목을 연다.
  별도 로그아웃 버튼은 제거했다. 프로필을 선택하기 전에는 로그아웃 요청이나 화면 이동을 하지 않는다.
- 보호자 설정의 중복된 ‘아이 관리로 이동’ 섹션은 제거했다. 아이 관리는 주 메뉴에서 접근한다.
  담당자 운영 설정과 아동의 음성·접근·보호자 설정 권한은 유지한다.
- 프로필은 네이티브 dialog 모달로 열고 기존 화면과 편집 초안을 뒤에 유지한다.
  Esc·닫기·바깥 클릭으로 닫는다. 배경 조작을 막고 닫은 뒤 PC에서는 톱니바퀴,
  작은 화면에서는 주 메뉴 펼치기 버튼으로 초점을 돌린다. 팝업은 body 스크롤을 잠근다.
- 계정 메뉴는 방향키·Home/End로 선택하고 Esc 또는 Tab으로 닫을 수 있다.
  메뉴 Esc가 작은 화면의 사이드바까지 닫지 않도록 분리했다.
- 프로필 저장과 로그아웃은 기존 API를 사용하며, 로그아웃 전 미저장 변경 확인을 유지한다.

## 검증 기록

- 프런트엔드 빌드 및 `git diff --check` 통과. 기존 큰 JS 청크 경고 유지.
- 격리 Chrome/모의 계정에서 두 항목·별도 로그아웃 제거, 메뉴 방향키·Esc·초점 복귀,
  프로필 모달·중복 아이 관리 없음·프로필 저장·명시적 로그아웃 및 세션 제거를 확인했다.
- 390/320px에서 메뉴 Esc가 사이드바를 유지하고 모달 가로 넘침 없음과 닫기 초점 복귀를 확인했다.
  아동형 여러 설정 탭도 320px에서 유지되고 방향키 이동이 동작한다.
- 첫 PC 초점 검사는 검수 뷰포트가 작은 화면이어서 모바일 복귀 대상을 PC 기준으로 판정해 실패했다.
  검수 화면 크기를 명시한 재검사와 최종 전체 흐름은 통과했다.
- 실제 계정 데이터는 변경하지 않았다. 실제 iPad 터치·스크린리더·실서버 왕복은 미실행이다.
