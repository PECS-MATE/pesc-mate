# 나의 문장 상단 배치

- 그림으로 말하기 화면의 문장판을 제목 바로 아래로 이동했다.
  빠른 표현·복구 표현·리더기보다 먼저 보이며 DOM 순서도 일치한다.
- 문장판을 카드 목록 workspace 밖으로 옮겨 카드 목록 끝에서 고정이
  해제되지 않도록 했다. 화면 상단에 닿으면 sticky로 유지한다.
- 모바일에서 sticky를 해제하던 규칙을 제거했다. 모든 화면 크기에서
  최대 높이는 화면의 48%이고, 긴 내용은 문장판 안에서 스크롤한다.
- 카드 목록으로 이동할 때 고정 문장판 아래로 제목이 가려지는 것을 줄이도록
  scroll-margin을 지정했다.
- 문장판은 하나만 렌더링하며 카드 드래그·순서·제거·자동 생성·발화와
  기존 초점 ref를 그대로 유지한다. 다른 역할과 화면에는 표시하지 않는다.

## 검증

- 프런트엔드 프로덕션 빌드와 변경분 공백 검사 통과.
- 기존 500kB 초과 JS 청크 경고는 남아 있다.
- 실제 브라우저·실기기에서 스크롤, 저높이 화면, 카드 드래그, 키보드 초점,
  USB 태깅·TTS의 회귀 검수는 미실행이다. 구현 완료와 검수 완료는 구분한다.
- 카드 원본 사진과 빌드 결과물은 커밋에서 제외한다.
