# 추천 카드·이전 문장 도구 제거

- 말하기 화면에서 `추천 카드 보기`와 `이전 문장·다시 듣기` 영역을 제거했다.
- 마지막 발화/직전 문장 보관·복원 상태와 추천 수 배지, 사용하지 않는 스타일을 정리했다.
- 다른 곳에서 참조하지 않는 프런트엔드 추천 패널 컴포넌트를 삭제했다.
  이에 딸린 추천 피드 갱신·노출/선택 요청은 더 이상 말하기 화면에서 실행되지 않는다.
  변경 전 소스는 Git 이력에서 복구할 수 있다.
- 추천 전용 상태·빈 응답 자리와 이미지 복원·캐시 필드를 정리했다.
  기존 캐시의 추천 데이터는 더 이상 복원하지 않는다.
- 현재 문장·카드 선택·스피커·반짝이·비우기·카드 도구·즐겨찾기는 유지한다.
- 보호자용 연습 제안·카드판 정리 제안과 백엔드 추천 API·기존 이용 기록은 변경하지 않는다.

## 검증

- 프런트엔드 빌드와 변경분 공백 검사 통과. 기존 500kB 초과 청크 경고는 남아 있다.
- App에서 제거한 컴포넌트·상태·복원 함수의 잔여 참조가 없는지 정적으로 확인했다.
- 실제 브라우저·실기기·TTS·문장 생성·RFID·오프라인 회귀 검수는 미실행이다.
- 사용자 카드 이미지·PDF·수정 중인 제작 체크리스트는 포함하지 않는다.
