# 소리 듣고 카드 찾기

2026-10-24 학습 콘텐츠 확장의 첫 활동. **연습하기 → 연습 종류 → 소리 듣고 카드 찾기**에서
시작한다. 기존 단어·그림 맞추기도 유지한다. 실제 의사소통·청력·언어 능력을 평가하거나
진단하는 검사가 아니다.

## 출제와 재생

기존 보호자 학습 설정의 카테고리·문제 수·보기 수·반복·재도전을 사용한다. 선택 범위에서
그림이 있는 카드만 후보로 사용하며 문제당 정답 1개와 중복 없는 보기를 만든다.
새 문제를 자동 재생하지 않는다. **문제 소리 듣기**를 누르고 재생 시작 콜백이 와야
답 카드를 고를 수 있다. 문제의 정답 그림은 미리 보여 주지 않고 보기에 그림·단어를 함께
표시한다. 재생 시작은 실제 청취 확인이 아니다. 시간 제한 때문에 자동 실패 처리하지 않는다.

기기 TTS를 기존 사용자 음량·속도·목소리 설정으로 재생한다. 온라인 음성 공급자의 전송
특성은 기존 음성 정책과 같으며 별도 서버 TTS 공급자나 음성 업로드는 도입하지 않는다.
오프라인 문제 재생은 `localService=true`인 한국어 음성이 있어야 한다. 없거나 재생이
실패하면 안내·재시도를 제공하고, 연습 목록에서 그림·단어 연습을 고를 수 있다.
같은 문제의 재생 중지 후 다시 듣기도 가능하다.

문제 음성은 공용 재생기를 사용하지만 의사소통 발화/선택 이력·마지막 말·문장에는 넣지
않는다. 상단에는 정답 대신 **학습 문제 음성**으로 표시한다. 긴급·복구·기본 말하기는
문제 음성을 대체할 수 있다. 문제 화면을 나갈 때는 자신이 시작한 재생만 정리하므로
그 뒤 시작된 긴급 발화를 중단하지 않는다. 학습 때문에 말하기를 잠그지 않는다.

## 결과·재개·동기화

`activity_type=sound_picture_match`, `content_version=sound-picture-v1`을 학습 결과에
기록한다. 기존 활동은 `word_picture_match`, `word-picture-v1`이다. 종류와 버전이 맞지
않으면 422로 거절한다. 과거 저장 문서의 없는 버전은 null로 읽으며 임의로 채우지 않는다.
버전 없는 구형 요청은 해당 활동의 현재 v1으로 저장해 기존 클라이언트를 유지한다.

문제 순서·결과·종류·버전·요청 ID를 기존 아동별 학습 캐시에 보관한다. 새로고침해도
같은 활동/문제로 재개하고, 아직 답하지 않은 소리 문제는 다시 듣게 한다. 지원하지 않는
활동/버전은 강제로 복원하지 않고 새 연습 선택을 안내한다. 오프라인 완료는 같은 활동·
버전·UUID를 기존 학습 대기열로 전송하므로 재연결/재시도에도 한 번 저장된다.

서버는 기존 합계/문제별 결과 일치·동의·역할·소유자 검사를 유지한다. 단어별 집계에는
두 활동의 관찰 결과가 함께 포함되며 자동 능력 판정이나 난이도 추천을 추가하지 않는다.
학습 진행/개인정보 JSON에 버전을 포함하고 학습 기록 CSV/JSON에도 `content_version`을
추가한다. 의사소통 기록과 합치지 않으며 기존 개인정보 삭제/보존 범위를 따른다.
동의가 없으면 앞선 [기록 없는 연습](GUARDIAN_CONSENT_FLOW.md)에 따라 결과·진행·대기열을
저장하지 않고 현재 화면에서만 사용한다.

## 검증과 남은 범위

Node 96·React 179개, 총 275개와 빌드 통과. 새 컴포넌트 5개는 기존 활동 유지·자동 재생
없음·시작 전 선택 차단·오류/재시도·이전 문제 콜백 폐기·정리·완료/저장 상태를 검사한다.
Windows 백엔드 386개 실행은 통과했으나 환경 의존 심볼릭 링크 2개를 제외했다.
후속 Linux 백엔드 386개·격리 MongoDB 전체 통합 86개 통과(제외 없음).
첫 통합 실행에서 최초 저장 응답과 재전송 응답의 완료 시각 표기가 달라 1개가 실패했다.
BSON 밀리초 정밀도·UTC 표기를 응답에서 통일해 기존 DB를 고치지 않고 재전송 응답을
일치시켰다. 같은 전체 단위·통합 검사를 재실행해 모두 통과했다.

Chromium 10개 통과: 소리 학습의 명시 재생·새로고침 재개·학습에만 저장·오프라인 완료와
한 번 동기화·긴급 발화 우선 및 화면 이탈 정리, 기존 학습/오프라인/개인 카드/보호자 동의/
복구 흐름을 실제 API·임시 MongoDB에서 확인했다. 보고서:
`.local-validation/learning-guardian-20261024/browser-sound-final/report/`.

추가 Chromium 1개도 통과했다. 동의 없는 소리 학습 10문제를 실제 화면에서 완료하고,
서버 학습/발화/의사소통 결과·기기 진행·대기열·관련 POST/PATCH가 없는지 확인했다.
보고서: `.local-validation/learning-guardian-20261024/browser-recordless-learning/report/`.
각 임시 스택은 정리했다. 사용자 사진·DB·운영 볼륨과 원격 저장소는 변경하지 않았다.

실제 기기 음질·아동 과업·스크린리더 검수와 전체 `verify:full`은 미실행이다.
문장 순서 만들기·상황 연습·보호자 지정 문제 세트·적응 난이도·일일 코스 등 나머지
B2-01 항목은 별도 후속 범위다. 콘텐츠 버전은 추가했지만 전체 출제 근거/콘텐츠 이력
체계까지 완료한 것은 아니다.

후속 검증: 같은 날짜의 [문장 순서 학습](SENTENCE_ORDER_LEARNING.md) 개발 후 전체
`verify:full` 845개와 빌드·정리가 통과했다. 위 당시의 전체 미실행 상태와 구분하며,
이 후속 전체 실행은 소리 학습과 동의 없는 연습 회귀도 포함한다. 실제 기기 검수는 계속 별도다.
