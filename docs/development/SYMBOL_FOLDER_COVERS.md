# 대표 그림이 보이는 카드·폴더 격자

## 변경

- 사용자가 채팅으로 제시한 3열 카드·폴더 예시를 참고했다.
  홈 카드 3장 다음에 폴더를 같은 격자로 나열한다.
- 폴더는 상단 탭이 있는 흰색 윤곽으로 표현한다. 프레임은 코드 내 SVG이며
  별도 비트맵이나 외부 이미지 라이브러리를 추가하지 않는다.
- 폴더 안에서 실제 이미지가 있는 첫 카드를 대표 그림으로 크게 표시한다.
  첫 카드에 이미지가 없으면 뒤의 카드도 확인하며, 이미지가 하나도 없으면
  폴더 아이콘을 사용한다. 카드명별 파일 경로나 대표 이미지 ID를 하드코딩하지 않는다.
- 대표 사진은 기존 카드 이미지 연결 함수를 재사용하며 원본을 수정하거나
  복제·업로드하지 않는다. 폴더 이름과 카드 수는 버튼 접근성 이름으로 제공한다.
- 빈 분류 폴더는 숨기되 모든 카드 진입점은 유지한다. 저장된 카드판과
  상황 폴더 내부 순서는 변경하지 않는다.
- 상단 분류는 한 줄의 스크롤 가능한 알약 모양 버튼으로 정리했다.
  모바일 기본 3열, 큰 카드 설정 2열이며 큰 글자 설정도 유지한다.
- 기본 화면은 그림·이름만 강조한다. `카드 도구`를 펼치면 기존 개별 듣기와
  즐겨찾기를 조작할 수 있다. 도구 버튼과 내부 조작은 44px 이상이다.
- 폴더와 카드 바깥의 중복 큰 패널 테두리를 제거했다. 문장판과 발화 동작은 유지한다.

## 확인 결과

- 최종 프런트엔드 빌드와 변경분 공백 검사 통과.
  기존 500kB 초과 JS 청크 경고는 남아 있다.
- 실제 분리 Chrome 데모 계정에서 320·390px는 3열이며 1280px에서도
  페이지 가로 넘침이 없었다. 첫 3개는 카드, 다음 항목부터 폴더인 DOM 순서를 확인했다.
- 로컬 데모의 비어 있지 않은 폴더 8개 중 7개는 대표 이미지, 나머지는
  폴더 아이콘으로 표시했다. 이전 중간안의 작은 두 장 미리보기는 제거했다.
- 390px 화면을 캡처·시각 확인했다. 탭 모양의 폴더와 대표 그림·이름을 확인했다.
- 카드 도구를 펼치면 즐겨찾기 3개와 듣기 버튼이 표시되며, 폴더 열기/돌아오기와
  해당 제목/폴더로의 초점 이동을 확인했다.
- 검수 중 카드·즐겨찾기·발화 기록과 설정은 저장하지 않았다. 임시 로그인은
  로그아웃하고 분리 브라우저를 종료했다.
- 실제 듣기·추가 발화·RFID·큰 카드/큰 글자/고대비·키보드 스크롤 전체 동선·
  다른 역할·실기기 터치·스크린리더 검수는 미실행이다.
- 사용자 카드 사진·PDF·캡처와 수정 중인 제작 체크리스트는 커밋하지 않는다.
