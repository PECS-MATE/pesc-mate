# 서비스 소개 랜딩과 인증 진입

2026-10-28 사용자 요청으로 로그인 전 첫 화면에 PESC MATE 소개를 구성했다.
기존 프로젝트의 색상·마스코트·카드와 이용 흐름을 사용한다.

## 구성과 동선

- 첫 화면: 프로젝트 소개, 카드 3장으로 문장을 표현하는 정적 사용 예시와 시작하기.
- 주요 기능: 그림으로 말하기, 단어·소리·문장 연습, 실물 카드 연결.
- 이용 순서: 로그인·프로필 선택 → 카드 선택·입력 → 확인하고 말하기.
- FAQ: 리더기 선택 사용, PC·태블릿과 USB 브라우저 조건, 오프라인 준비, 개인정보·기록 관리.
- 하단: 기존 로그인·사용자 가입 폼과 프로젝트 푸터. 존재하지 않는 문의·상점·영상·후기 링크는 만들지 않는다.

상단 로그인은 아이디 입력창으로, 시작하기는 가입의 이름 입력창으로 스크롤하고 초점을 이동한다.
첫 진입 때 하단 폼으로 자동 초점을 주지 않으므로 소개가 먼저 보인다. 가입 전환 시 개인정보 동의는
체크하지 않은 상태로 시작하며 기존 필수 동의와 명시 제출을 유지한다. 보기만 해서는 인증·기록 API를
호출하지 않으며 예시가 실제 문장 생성·리더기 연결·음성 재생을 실행하지 않는다.

로그인·프로필 설정 뒤 앱 화면의 처음으로 이동하고, 유효한 기존 세션은 소개를 거치지 않고 앱으로
복원한다. 로그아웃하면 소개 처음으로 돌아가며 가입 초안·동의 체크와 비밀번호를 초기화한다.
인증 오류는 기존 폼에서 표시하고 해당 위치로 이동한다. 별도 라우터·새 인증 API·외부 서비스를
추가하지 않았다. 기존 프로필·동의·지원 권한·오프라인 세션 정책을 유지한다.

## 표현과 자산

예시 카드는 기존 카드명→PNG 파일 매핑을 재사용한다. 마스코트도 기존 컴포넌트를 사용하며
개인 사진·실제 아동 정보·외부 사진·새 생성 이미지를 추가하지 않는다. 사용 예시임을 표시하고
실제 사용자 집계, 후기, 학습 점수·성과, 임상 효과나 모든 기기에서의 실물 연동 성공을 주장하지 않는다.
새 스타일은 `landing.css`의 `.landing` 범위로 제한하고 로그인된 앱의 디자인에 섞이지 않도록 한다.
FAQ는 기본 카드 말하기와 실물 연결의 PC 조건, 사전 캐시·기기 음성 조건을 구분한다.
