## 현재 현황

현재 PNG는 40장이다. 기존 계획 41종 중 30종의 파일이 있고 11종이 없다.
나머지 10장은 기존 계획 밖에서 추가한 이미지다.
파일 존재는 이미지 품질 승인·사용자 이해 확인·DB 등록 완료를 뜻하지 않는다.

| 구분 | 파일이 있는 카드 |
| --- | --- |
| 사람 | 나, 엄마, 아빠, 선생님 |
| 음식·음료 | 물, 밥, 사과, 우유 |
| 행동·생활 | 가다, 놀다, 마시다, 먹다, 쉬다, 씻다, 입다, 벗다, 자다, 보다, 듣다 |
| 요청·선택·응답 | 그만, 기다려 주세요, 네, 다른 것, 다시, 도와주세요, 모르겠어요, 싫어요, 좋아요, 주세요 |
| 신체·상태 | 머리, 배, 손, 여기가 아파요, 불편해요, 무서워요, 시끄러워요, 아파요 |
| 장소 | 집, 학교, 화장실 |

`다른_것.png`는 현재 올바른 파일명으로 존재한다. 다시 제작하거나 이름을 바꿀 필요가 없다.
계획 밖 10장은 씻다·입다·벗다·자다·보다·듣다·아빠·선생님·학교·주세요다.

## 기존 계획 이후 확장 후보 — 4장

`문.png`, `열다.png`, `공.png`, `책.png`는 아직 파일이 없는 확장 후보다.
먼저 위 11장을 보완한 뒤 실제 사용할 어휘를 골라 추가한다.
이미지 파일 추가만으로 DB 카드·RFID 연결이 새로 등록되지는 않는다.

## 제작 기준

- 마스코트 없이 흰 배경. 사물은 사진형, 동작·상태는 단순한 사람 그림상징.
- 정사각형 1024×1024px 권장. 글자·워터마크·장식 테두리는 넣지 않는다.
- 파일명은 실제 표시 단어와 일치시키고 공백은 `_`로 바꾼다.
- 같은 세트의 선·구도·여백을 맞춘다. 원본 크기와 웹·실물 식별성은 별도로 확인한다.
