기존 41종 목록과 정확히 매핑되는 파일은 22장이다. 그 외 4장은
파일명 확인 대상 1장과 확장 카드 3장이다. 파일이 있다고 의미·규격 검수가
끝난 것은 아니며 이 목록에서는 PNG 내부 그림을 시각 검수하지 않았다.

### 다시 만들지 말고 파일명부터 확인 — 1장

- [ ] `다른것.png` → 표시 어휘 `다른 것`에 맞는 `다른_것.png`로 이름 정리

백엔드 기본 카드의 표시 단어는 `다른 것`이다. 프런트엔드는 공백을 `_`로
치환하므로 현재 이름은 기본 카드와 자동 연결되지 않는다. 새 이미지를 만들
필요는 없으며 이번 문서 작업에서는 실제 파일명을 변경하지 않았다.

### 확장 이미지 — 3장

- 씻다, 입다, 자다

기존 41종 제작 목록 밖에 있는 이미지다. 이미지 추가만으로 DB 카드가 새로
등록되지는 않으므로 카드 등록 여부는 별도로 확인해야 한다.

## 기존 계획에서 새로 제작할 카드 — 18장

아래 순서는 프로젝트 제작 작업 순서이며 아동별 교육·중재 순서가 아니다.
각 체크는 파일 준비용이며 의미 검수와 웹·실물 확인은 별도로 진행한다.

- [ ] 아니에요 — `아니에요.png`

확인하고 구별되는 표현으로 제작한다. 현행 제작 가이드의 개별 프롬프트를 따른다.

## 기존 계획 이후 확장 후보 — 우선 10장

아래는 신규 제작 제안이다. 현재 41종 미완료 수에는 포함하지 않으며,
필요한 단어를 선택해 카드 데이터와 이미지를 함께 추가한다.

실제 생활에 맞춰 선택하고 필요한 경우 동의받은 개인 사진을 사용한다.

## 제작 기준과 확인 기록

- 마스코트 없이 흰 배경. 사물은 사진형, 동작·상태는 단순한 사람 그림상징.
- 정사각형 1024×1024px 권장, 글자·워터마크·장식 테두리 제외.
- 파일명은 실제 표시 단어와 일치시키고 공백만 `_`로 치환한다.
- 로컬 PNG 26장, 기존 목록 41종, 정확한 파일명 일치 22종,
  이름 확인 1종, 신규 제작 필요 18종, 계획 밖 이미지 3종을 정적으로 대조했다.
- 변경분 공백 검사 통과. 이미지 수정·이름 변경·DB 조회/등록·이미지 내용 및
  규격 검수·빌드·브라우저·실기기 검수는 미실행이다. 원본 사진은 커밋하지 않는다.
- 상세 표현은 [제작 가이드](CARD_IMAGE_PRODUCTION_GUIDE.md), 기존 진행표는
  [제작 체크리스트](CARD_IMAGE_CHECKLIST.md)를 참고한다. 기존 진행표의 수동
  집계는 최신 파일 현황과 다르므로 이번 확인일의 수치는 이 문서를 기준으로 한다.
