# 문장판 아이콘 도구모음

- 나의 문장 제목 옆에 휴지통·스피커·반짝이 버튼을 순서대로 배치했다.
- 휴지통은 기존 전체 비우기 확인을, 스피커는 선택 카드 그대로 말하기를
  유지한다. 반짝이는 최초 문장 생성 또는 기존 문장 다시 만들기를 실행한다.
- 기존 700ms 자동 생성은 유지하며 중복 실행 방지와 보호자 동의·온라인·
  생성 중·발화 중 제한을 유지한다. 단어 모드 자체를 바꾸지는 않는다.
- 아래의 중복 말하기·다시 만들기 버튼은 제거한다. 생성된 문장을 읽는
  `이 문장 말하기`와 오류 시 대체 발화는 유지한다.
- 공통 SVG 아이콘에 휴지통·반짝이를 추가하고 기존 스피커를 재사용한다.
- 각 버튼은 48px이며 접근성 이름·툴팁을 제공한다. 공간이 부족하면 제목과
  도구모음은 줄바꿈하되 세 도구는 한 줄로 유지한다. 원본 사진은 변경하지 않는다.

## 검증

- 프런트엔드 빌드와 변경분 공백 검사 통과.
- 기존 500kB 초과 JS 청크 경고는 남아 있다.
- 실제 브라우저·실기기의 반응형 표시, 키보드·스크린리더, 생성 API·TTS·
  비우기 상호작용 검수는 미실행이다.
- 사용자 추가 사진과 빌드 결과물은 커밋에서 제외한다.
