# 음성 재생 상태 표시 단순화

- 상단의 음성 재생 중·준비 중·일시 정지 문구와 발화 내용 미리보기를
  시각적으로 제거하고 배너 배경·테두리·그림자를 정리했다.
- 재생 중 일시 정지, 정지 중 재개, 중지 버튼은 유지한다.
  제어 버튼의 최소 높이는 44px이다.
- 스크린리더용 상태 안내는 시각적으로 숨긴 status 영역에서 유지한다.
- 음성 재생·기록·오류 안내와 다른 도구의 발화 중 제한은 변경하지 않는다.

## 검증

- 프런트엔드 빌드와 변경분 공백 검사 통과.
- 기존 500kB 초과 청크 경고는 남아 있다.
- 실제 브라우저에서 TTS·일시 정지·재개·중지 및 스크린리더 검수는 미실행이다.
- 사용자가 추가한 사진과 빌드 결과물은 커밋에서 제외한다.
