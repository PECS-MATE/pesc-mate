# 보호자 A4 카드 편집기

## 사용 경로

보호자 → 개인 카드 관리 → 아이 선택 → **A4 그림카드 만들기·인쇄**.
기존 `cards_manage` 연결 권한과 계정별 진입 조건을 유지한다.
OCR·다중 카드 자동 분리·RFID 순차 매핑은 이번 범위가 아니다.

## 편집 흐름

1. 새 사진·카메라 촬영 또는 등록된 개인 카드를 보관함에 추가한다.
   새 사진의 파일명을 이름·뜻으로 자동 입력하지 않는다. 보관함에는 이미지만 표시하고
   칸에 넣은 뒤 오른쪽에서 인쇄 이름을 입력한다. 등록된 개인 카드의 기존 이름은 유지한다.
2. 기본 A4 칸에 카드를 배치한다. 방향·크기·행열·여백 등 출력 설정은 프린트를 누른 뒤 조정한다.
3. 용지의 칸을 선택하고 보관함 카드를 누르거나 끌어 넣는다.
   보관함은 편집 박스 상단의 한 줄 이미지 목록이며 좌우 스크롤한다.
   사용 안내는 제목 옆 정보 아이콘을 눌렀을 때만 표시한다.
4. 칸 사이 드래그는 두 칸의 내용을 교환한다. 터치·키보드에서는 칸 선택 후
   보관함 카드 선택과 칸 비우기를 사용할 수 있다. 같은 카드를 여러 칸에 넣을 수 있다.
5. 오른쪽 설정에서 칸별 인쇄 이름·8~24pt 글자·그림 맞춤·1~2배 확대를 바꾼다.
   전체 보이기는 비율을 유지한다. 꽉 채우기와 확대는 일부 그림을 자를 수 있다.
6. 편집본을 다운로드하거나 프린트 버튼으로 설정 창을 연다.

### 용지와 배치 규칙

- 실제 A4 210×297mm 또는 297×210mm, 여백 5~20mm, 간격 0~10mm.
- 직접 구성은 최대 8열·10행이며 칸이 15mm 미만이거나 인쇄 영역을 벗어나면 거부한다.
  기본 양식은 정사각형이고 직접 구성은 용지의 가용 영역을 등분한 직사각형이다.
- 기본 4cm 세로 양식은 4열×6행 24칸, 최대 5쪽이다. 빈칸은 그대로 유지한다.
- 양식 변경 시 배치된 항목이 끝에서 잘리지 않도록 필요하면 쪽 수를 늘린다.
  5쪽을 넘기는 변경은 거부한다. 쪽 삭제는 마지막 쪽만 가능하며 내용이 있으면 확인한다.
- 빈칸 자동 채우기는 보관함 순서로 현재 빈칸만 채운다. 기존 칸을 덮어쓰지 않는다.
- 편집 화면의 배치·칸 속성은 최대 20단계 실행 취소/다시 실행을 지원한다.
  프린트 창의 용지 설정은 출력용 복사본에서만 변경하며 배치 이력에 넣지 않는다.
  보관함 이름/등록 상태 변경은 배치 이력 대상이 아니다.
  보관함 원본 제거와 편집본 불러오기는 배치 이력을 초기화한다.
- 30~100% 미리보기 배율은 편집 화면에만 적용하며 실제 인쇄 크기는 바꾸지 않는다.
  작은 화면에서는 보관함·용지·속성을 세로로 배치하고 용지 안에서 스크롤한다.

## 편집본 저장·불러오기와 개인정보

- **편집본 다운로드**는 `pecsmate-a4.json` 파일이다. 용지 설정·칸 배치·
  보관함 이미지 원본과 이름을 포함한다. PDF와 달리 다시 수정할 수 있다.
- 서버/DB/브라우저 영구 저장소에는 편집본을 자동 저장하지 않는다.
  화면을 떠나기 전에 다운로드해야 하며 개인 사진이 포함된 파일은 안전하게 보관한다.
- 최대 30MB, 보관함 60개 제한이다. 새 사진은 한 번에 20장, 장당 5MiB 이하의
  JPG·PNG·WebP를 허용한다. 촬영 파일도 같은 검사를 거친다.
- 불러오기는 형식·버전·선택 아이 ID·이미지 자료형·카드 식별값·배치/수치 범위를 검사한다.
  다른 아이의 파일·범위를 벗어난 배치·중복 식별값은 거부한다.
- 불러오기로 기존 편집을 교체하기 전 확인하며 실패 시 현재 편집을 유지한다.
  아이 계정 등록 체크는 항상 해제한다. 서버에 저장됐던 항목은 현재 등록 목록에 대조하고,
  확인되지 않으면 저장 여부 확인 필요로 표시해 자동 재등록을 막는다.
- 임시 이미지 URL은 원본 제거·편집본 교체·화면 이탈 때 회수한다.
  업로드/편집본 처리가 진행 중일 때는 배치와 인쇄 등 충돌하는 조작을 잠근다.

## 아이 계정 등록과 인쇄의 분리

- **보관함 카드 정보·아이 계정 등록**을 펼쳐 보관함 이름·뜻·분류를 수정한다.
- 전체 등록 체크를 켜고 카드별 등록 여부를 선택한 뒤 별도 저장 버튼을 눌러야 서버에 전송한다.
  인쇄만 하거나 편집본을 다운로드/불러오는 것은 아이 카드 등록이 아니다.
- 기존 제출/초안 활성화 API, 권한·동의·중복·용량·안전성 검사를 재사용한다.
  기존 카드 원본을 인쇄 편집으로 수정하거나 비활성/반려 카드를 재활성화하지 않는다.
- 이미 저장된 카드·불확실한 저장 결과는 자동 재전송하지 않는다. 부분 저장 결과를 표시한다.
- 칸의 이름·그림 확대·맞춤은 출력 전용이다. 아이 계정에는 보관함의 원래 사진과 등록 정보를 저장한다.
- 칸 비우기·보관함 제거는 서버 카드 삭제가 아니다. 카드 등록 후 아이 화면에서 다시 불러온다.
  고정 카드판이나 RFID 연결은 자동 변경하지 않는다.

## 인쇄

- **프린트 → 프린트 설정 → 프린트 → 브라우저 인쇄창** 순서다. 첫 버튼은 인쇄를 실행하지 않는다.
- 설정 창은 왼쪽 미리보기와 오른쪽 방향·4/5/6cm 크기·가로/세로 카드 수·이름 표시·단면/양면 선택으로 구성한다.
  여백·간격은 접힌 추가 항목에서 조정한다. 편집 화면에 같은 인쇄 설정을 반복하지 않는다.
  작은 화면에서는 세로로 쌓고 미리보기 내부를 스크롤한다.
- 설정 변경은 이번 출력용 복사본에만 적용한다. 취소·Escape로 닫아도 원본 배치와 편집본은 바뀌지 않는다.
  포커스는 설정 창 안에 두고 배경을 inert 처리하며 닫을 때 기존 포커스와 스크롤 상태를 복구한다.
- 양면은 각 용지의 앞면 그림 페이지 다음에 뒷면 이름 페이지를 생성한다.
  뒷면은 열 순서를 좌우 반전하고 용지 오른쪽에 정렬해 기본 정사각 양식의 남는 폭도 보정한다.
  이름 숨기기는 앞면에 적용하며 뒷면에는 카드 이름이 표시된다.
- 앱은 프린터 양면 옵션을 자동 설정하지 않는다. 브라우저 인쇄창에서 양면 인쇄 및
  세로는 긴 쪽/가로는 짧은 쪽 넘김을 직접 선택해야 한다. 프린터별 지원·종이 급지·정렬 검수는 남아 있다.
- 동일 출처 iframe에 버튼·설정 없는 출력용 용지만 렌더링한다. 사용자 문구는 React 텍스트로 처리한다.
- 그림 디코딩과 글꼴 준비 후 인쇄 창을 연다. 페이지 규칙에 A4 방향과 0 여백을 설정하고
  용지 안쪽 여백은 편집 설정으로 적용한다. 빈칸의 편집용 점선·선택 윤곽은 출력하지 않는다.
- 브라우저에서 A4, 설정한 방향, 배율 100%, 여백 없음, 머리글/바닥글 끄기를 확인한다.
  실제 프린터 크기·여백 지원과 PDF 페이지 수는 별도 확인이 필요하다.

- 기존 합성 사진 기반 편집·파일 왕복 검수를 포함해 격리 Chrome에서 재실행했다.
  첫 프린트 클릭 시 인쇄 호출 없음, 설정 창/배경 inert, Escape 취소 및 배경 복구를 확인했다.
- 방향을 세로로 바꾸고 가로 카드 수 3·이름 숨김·양면을 선택했다.

  세로 용지 규칙을 확인했다. 프린트 확정 시 대체 인쇄 함수 1회 호출을 확인했다.
- 설정 후에도 원래 편집 화면의 가로 A4 배치가 유지됐다. 390px 화면에서 문서 전체 가로 넘침 없음.
- 일회성 Node 검사로 두 쪽 뒷면의 열 반전·빈칸 보존·재반전 복원을 확인했다.
- 실제 인쇄창/PDF·프린터 양면·앞뒷면 정렬·자동 급지와 전체 보조공학 검수는 미실행이다.

### 파일명 자동 입력 제거

- A4 새 사진/촬영만 이름·뜻을 빈 값으로 시작한다. 일반 카드 일괄 등록의 파일명 규칙은 변경하지 않는다.
- 보관함에서 이름과 ‘이름 없음’ 표시를 제거하고 이미지와 접근성 이름만 제공한다.
- 이름을 입력하지 않은 칸은 앞면에 빈 이름 영역을 만들지 않는다. 오른쪽 인쇄 이름은 칸별이며,
  아이 계정 등록에 필요한 보관함 이름·뜻·분류는 기존 등록 영역에서 별도로 입력한다.
- 프런트엔드 빌드·공백 검사 통과. 기존 청크 크기 경고는 유지된다.
- 격리 Chrome에 임의 파일명의 합성 PNG를 넣어 보관함 이미지 전용 표시·접근성 이름·
  칸 이름 초기 빈 값·빈 이름 영역 없음·오른쪽에서 수동 입력 반영을 확인했다.
  실제 계정·DB는 사용하지 않았다. 실제 인쇄·아이 등록 API 검수는 미실행이다.

### 인쇄 설정 통합과 가져오기 도구 간소화

- 사진 추가·촬영·등록 카드 가져오기·편집본 열기·다운로드를 44px 아이콘 버튼으로 제공한다.
  공통 UiIcon 선 아이콘을 사용하고 각 버튼에 접근성 이름과 title을 붙인다.
- 파일 입력은 숨기고 직접 클릭한 아이콘으로만 연다. 등록 카드 선택 목록은 아이콘을 누를 때만 펼친다.
  펼치면 선택 목록으로 포커스를 옮기며 Escape로 닫고 원래 버튼으로 복귀한다.
  기존 진행 중 잠금·권한/오프라인 차단·파일 검사는 유지한다.
- 편집 화면의 용지 설정은 제거하고 배치 실행 취소/다시 실행만 아이콘으로 유지한다.
  인쇄 크기·여백·간격은 프린트 창으로 옮긴다. 칸별 이름·그림 편집은 오른쪽에 유지한다.
- 프런트엔드 빌드·변경분 공백 검사 통과. 기존 청크 크기 경고 유지.
- 격리 Chrome/합성 사진으로 아이콘 5개·이름·이미지 전용 보관함·설정 중복 제거·
  등록 카드 펼침/포커스/Escape 복귀·다운로드 동작·5cm 3×5 배치·15mm 여백 반영·
  취소 후 원본 10mm 여백 유지·390px 전체 가로 넘침 없음을 확인했다.
- 실제 파일 선택창·촬영·서버 카드 조회/등록·인쇄창/PDF·프린터와 전체 접근성 검수는 미실행이다.

### 상단 가로 보관함과 통합 도구 줄

- 실행 취소/다시 실행을 사진·카드·편집본 아이콘과 같은 도구 줄로 합쳤다.
  도구는 줄바꿈하지 않으며 작은 화면에서는 도구 줄 안에서 좌우 스크롤한다.
- 보관함은 편집 박스 전체 너비의 상단에 한 줄로 표시한다. 썸네일은 일정 크기로 유지하고
  보관함 안에서 좌우 스크롤하며 아래에는 용지와 선택한 칸의 속성을 배치한다.
- 정보 아이콘은 클릭·터치·키보드로 안내를 토글한다. aria-expanded/controls/describedby를
  제공하며 Escape로 닫고 정보 버튼으로 포커스를 돌린다. hover만으로 안내를 제공하지 않는다.
- 배치·드래그·이력·빈칸 채우기와 기존 등록/인쇄 기능은 유지한다.
- 프런트엔드 빌드와 변경분 공백 검사 통과. 기존 청크 크기 경고는 유지된다.
- 격리 Chrome에서 합성 PNG 16장으로 도구 7개 한 줄·보관함 한 줄/가로 넘침·
  보관함이 용지 위에 위치함·초기 안내 숨김·클릭 열기/Escape 닫기·포커스 복귀·
  실행 취소/다시 실행을 확인했다. 390px/320px에서도 두 줄이 각각 한 줄을 유지하고,
  보관함 좌우 스크롤이 가능하며 문서 전체 가로 넘침은 없었다.
- 최초 검수 스크립트의 중첩 문자열 구문 오류를 수정하고 재실행한 결과다.
  실제 계정·DB·장치는 사용하지 않았으며 영구 테스트 파일은 추가하지 않았다.
- 실제 터치 제스처·스크린리더·사진 촬영·아이 등록 API·PDF/프린터 검수는 미실행이다.
