# 보호자 A4 카드 편집기

## 사용 경로와 범위

- 보호자 계정 → 개인 카드 관리 → 관리할 아이 선택 → A4 그림카드 만들기·인쇄.
- `cards_manage` 권한이 있는 연결 아이에 대해서만 표시한다.
  지원 담당자·아동 계정에는 이 편집기 진입점을 제공하지 않는다.
- 새 JPG·PNG·WebP 사진은 한 번에 20장, 편집 목록은 최대 60장이다.
  등록된 개인 카드는 인증된 화면용 이미지 API에서 별도로 가져온다.
  작은 썸네일을 확대하거나 보관용 원본을 노출하지 않는다.
- 파일명의 밑줄은 공백으로 바꾸며 인쇄 문구·배치 순서·카드당 매수(1~4장),
  이름 표시 여부·한 변의 길이(4·5·6cm)를 편집한다.
- 기본값은 흰 배경 4×4cm, 재단용 얇은 테두리이다. 그림은 자르지 않고
  비율을 유지해 넣는다. 문구를 포함한 카드 전체가 지정 크기의 정사각형이다.
- A4 세로, 여백 10mm, 카드 사이 3mm로 여러 페이지에 자동 배치한다.
  한 페이지에는 4cm 24장, 5cm 15장, 6cm 12장이 들어간다.
- 미리보기는 물리적 크기 CSS를 사용하므로 작은 화면에서는 가로로 스크롤한다.
  실제 인쇄 크기는 프린터·브라우저 배율에 따라 달라질 수 있다.

## 인쇄와 저장의 구분

- 기본값은 인쇄 전용이다. 새 사진을 고르거나 인쇄해도 업로드하지 않는다.
  기존 카드 가져오기는 인증된 읽기 요청만 수행한다.
- `저장할 때 아이 계정에서도 사용`을 체크하고 `아이 계정에 카드 저장`을
  누르면 새 사진은 기존 `POST /cards/submissions`를 통해 해당 아이 전용
  `private` 카드로 저장·활성화한다. 뜻과 카테고리 등 기존 등록 조건이 필요하다.
- 선택한 기존 개인 카드가 초안이면 기존 제출 API로 사용을 시작한다.
  사용 중인 카드는 중복 등록하지 않고 반려·비활성 카드는 재활성화하지 않는다.
  공유 승인이나 모든 아이에게 공개하는 작업은 수행하지 않는다.
- 기존 API의 연결·관리 권한·보호자 동의·할당량·중복 이름·이미지 안전성 및
  해상도 검사를 재사용한다. 새 권한 우회 경로나 새 서버 API는 추가하지 않는다.
- 아이 화면은 카드를 다시 불러오거나 로그인하면 기존 카드 목록으로 표시된다.
  실시간 푸시·자동 로그인·고정 카드판 슬롯/순서 변경은 수행하지 않는다.
- 체크 해제나 인쇄 목록에서 빼기는 이미 저장된 카드의 삭제·비활성화가 아니다.
  등록 후 인쇄 문구를 바꿔도 아이 카드 원본의 이름·뜻·사진은 변경하지 않는다.
- 순차 저장 결과를 각 항목에 표시한다. 네트워크 오류·서버 오류·권한 오류처럼
  저장 결과가 불확실한 항목은 자동 재전송하지 않는다. 등록 목록 다시 불러오기로
  확인한 뒤 등록된 항목을 선택해 사용한다. 중간 성공은 되돌리거나 중복 전송하지 않는다.

## 인쇄 처리와 개인정보

- 별도 동일 출처 iframe에 React로 카드만 렌더링한다. 사용자 문구를 HTML로
  조합하지 않는다. 이미지 디코딩·글꼴 준비 후 그 문서의 인쇄 창을 연다.
- 앱 메뉴·관리 설정·아이 계정명 등은 인쇄 문서에 넣지 않는다.
- 브라우저 인쇄 창에서 A4 세로, 배율 100%, 머리글·바닥글 끄기를 확인한다.
  PDF 저장은 브라우저 인쇄 대상에서 선택한다. 프린터 실제 출력은 별도 검수가 필요하다.
- 인쇄용 편집 상태는 서버나 브라우저 영구 저장소에 저장하지 않는다.
  화면 이탈·아이/계정 변경 시 해제하고 미리보기 Blob URL도 회수한다.
  인쇄 전용 사진은 화면을 나가기 전에 인쇄하거나 PDF로 저장해야 한다.
- 사용자가 추가한 저장소 카드 PNG는 수정하거나 커밋에 포함하지 않는다.

## 검증 상태

- JSX 2개(`App.jsx`, `CardPrintEditor.jsx`)와 CSS 2개의 정적 구문 검사를
  읽기 전용·네트워크 없는 기존 로컬 Docker 이미지에서 통과했다.
- 변경분 공백 검사는 통과했다. 자동 테스트·전체 빌드는 미실행이다.
- 실제 브라우저 인쇄/PDF·프린터 실측·DB 등록·계정 전환·권한 회수·이미지
  실패 및 불확실한 저장 결과 검증은 미실행이다. 동작 검증 완료로 표시하지 않는다.
- 사용자 확인 항목: 4·5·6cm 출력 크기, 여러 페이지 마지막 빈 페이지 여부,
  이름 긴 카드·이름 미표시·투명 이미지·복수 매수, 인쇄 창 취소 후 재인쇄,
  미체크 시 업로드 없음, 체크 후 선택 아이만 사용 가능, 초안 활성화,
  중복 이름·동의 없음·권한 없음·오프라인 차단, 부분 저장 후 목록 갱신,
  아이 계정에서 새 카드 불러오기, 화면 이탈 시 인쇄 편집 상태 해제.
