# 아이패드 프레임 시연 화면

PECS MATE의 기능을 아이패드 형태의 가로 프레임 안에서 자동 소개하는 촬영용 페이지다.
앱 서버를 평소처럼 실행한 뒤 같은 주소의 `/promo-ipad.html`을 연다.
예: 개발 서버가 `http://localhost:5173`이면 `http://localhost:5173/promo-ipad.html`.

1. 페이지를 열면 홈 → 카드 선택 → 문장 완성 → 연습 → 마무리 순서로 자동 재생한다.
2. 민트 또는 흰 배경을 고르고 전체 화면으로 전환한다.
3. 촬영 모드를 누르면 설정 버튼이 사라진다. 화면 녹화는 별도 녹화 도구로 실행한다.
4. Esc로 설정 버튼을 복원한다. 키보드 Tab으로 왼쪽 위 복원 버튼에 접근할 수도 있다.

11개 장면을 각각 2.6초씩, 총 28.6초 주기로 반복한다.
일시정지·재생, 처음부터, 다음 장면 버튼으로 흐름을 조절할 수 있다.
동작 줄이기를 사용하는 환경에서는 일시정지 상태로 시작하며 재생 버튼으로 시작한다.

기본 자동 시연은 로그인 없이 동작하는 예시 화면이며 실제 서비스의 홈 컴포넌트,
그림카드, 아이콘, 디자인 색상을 재사용한다. 문장 출력과 정답은 연출된 예시이고
음성은 재생하지 않는다. 계정·기록 API를 호출하거나 데이터를 저장하지 않는다.
`/?promo=demo`로 시연 화면만 열 수도 있다.

‘실제 앱 조작’ 버튼으로 이전처럼 실제 앱을 열 수 있다.
이 모드에서는 기존 계정과 서버 연결을 사용하며 자동 전환은 하지 않는다.
태블릿 내부 화면은 1194×886이며 브라우저 크기에 맞춰 프레임 전체를 축소한다.
정지 이미지나 영상 파일을 자동 생성하는 페이지는 아니다.

## 검증 기록

- Node assert로 28.6초 타임라인, 카드 순차 선택, 연습 장면, 반복 초기화 확인: 통과.
- JSDOM으로 배경 선택, 촬영 모드와 Esc 복원, 재생 상태 메시지,
  실제 앱/자동 시연 전환, 320·768·1024·1440 너비의 축소 계산 확인: 통과.
  실제 브라우저 레이아웃 및 iframe 내부 재생 버튼 연동 확인을 대체하지 않는다.
- 시연 카드 8개의 실제 그림 파일 존재 확인 및 `git diff --check`: 통과.
- JSX 파서 검증: 설치된 Rolldown의 Windows 네이티브 바인딩 누락으로 실패.
  같은 실행의 후속 검사는 중단되어 JSDOM 검사를 별도 실행해 통과했다.
- 브라우저 시각 확인, 실제 로그인·음성·마이크·전체 화면·녹화 동작: 미실행.
- 빌드: 요청 범위에 없어 미실행.
- Serena 도구가 제공되지 않아 기존에 확인된 파일만 읽었다. 앱 소스 검색은 미실행.
