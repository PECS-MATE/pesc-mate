# 아이패드 프레임 시연 화면

기존 PECS MATE를 아이패드 형태의 가로 프레임 안에서 직접 조작하는 촬영용 페이지다.
앱 서버를 평소처럼 실행한 뒤 같은 주소의 `/promo-ipad.html`을 연다.
예: 개발 서버가 `http://localhost:5173`이면 `http://localhost:5173/promo-ipad.html`.

1. 프레임 안에서 로그인하고 시연할 화면을 준비한다.
2. 민트 또는 흰 배경을 고르고 전체 화면으로 전환한다.
3. 촬영 모드를 누르면 설정 버튼이 사라진다. 화면 녹화는 별도 녹화 도구로 실행한다.
4. Esc로 설정 버튼을 복원한다. 키보드 Tab으로 왼쪽 위 복원 버튼에 접근할 수도 있다.

실제 앱을 같은 출처의 iframe으로 표시하므로 기존 계정과 서버 연결을 사용한다.
태블릿 내부 화면은 1194×886이며 브라우저 크기에 맞춰 프레임 전체를 축소한다.
정지 이미지나 영상 파일을 자동 생성하는 페이지는 아니다.

## 검증 기록

- Node VM으로 인라인 JavaScript 구문과 필수 버튼·앱 iframe 참조 확인: 통과.
- `git diff --check`: 통과.
- 브라우저 시각 확인, 실제 로그인·음성·마이크·전체 화면·녹화 동작: 미실행.
- 빌드: 요청 범위에 없어 미실행.
- Serena 도구가 제공되지 않아 기존에 확인된 파일만 읽었다. 앱 소스 검색은 미실행.
