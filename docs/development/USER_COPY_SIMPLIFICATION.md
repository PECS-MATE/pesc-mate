# 사용자 화면 설명 간소화

- 나의 의사소통 기록 제목 아래 이름·기간·문장 저장 기준 반복 문구와 집계 설명을 사용자 화면에서 제거한다.
- 기간 선택 버튼, 저장한 문장·사용한 카드 지표 이름, 기록과 빈 상태 안내는 유지한다.
- 홈 말하기·연습하기의 반복 설명, 주제별 카드의 유도 설명과 빠른 표현의 반복 안내를 제거한다.
- 선택한 카드 수는 이어서 말하기에 필요한 실제 상태이므로 유지한다.
- 사용자 연습 화면의 기록 분리 설명을 숨기고 보호자·지원자의 집계 안내는 유지한다.
- 오류, 권한·개인정보, 삭제 확인, 연습 수행 지시 및 스크린리더 조작 안내는 삭제하지 않는다.

## 검증

- 프런트엔드 빌드와 공백 검사 통과. 기존 500kB 청크 경고는 유지된다.
- 실제 브라우저 화면 및 보조공학 조작 검수는 미실행이다.
