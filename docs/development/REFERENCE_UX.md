# 새 참고 화면의 활동 UX 반영

2026-10-28 사용자 요청: 새 이미지를 참고해 UX만 수정하고 검사는 사용자가 직접 수행한다.
참고 자료는 프로젝트 루트의 `uxpilot-export-10-28-26 (1).pdf` 7개 화면이다.
색상이나 화면을 그대로 복제하기보다 기존 기능의 정보 배치·조작 동선을 반영한다.

## 적용 범위

| 참고 화면 | 기존 기능에 반영한 UX |
|---|---|
| 랜딩·홈 | 앞선 랜딩·활동 홈 구현을 유지한다. |
| 단어 연습 | 문제 그림·소리 듣기와 답 선택을 중앙에 크게 배치하고 진행·피드백·다음 조작을 구분한다. |
| 카드 등록 | 관리자 공용 칩 등록을 인식 → 그림카드 선택 → 확인 후 저장 단계로 표시한다. 인식/UID와 카드 선택/미리보기를 두 패널로 묶는다. |
| 그림으로 말하기 | 선택 문장을 카드판 앞에 배치해 스크롤해도 위에 남게 하고, 선택 카드는 순서대로 가로 표시한다. 생성 문장과 발화 조작을 강조한다. |
| 리포트 | 기존 실제 집계·카테고리 사용과 자주 사용한 카드를 카드형 패널과 순위 목록으로 정리한다. |
| 카드 인쇄 화면 | 기존 카드 목록의 그림·이름·분류 계층을 정리하는 참고로 사용한다. 인쇄·PDF 기능을 새로 구현한 것은 아니다. |

말하기·연습하기의 `집중 화면`은 사이드 메뉴를 접는 화면 배치 전환이다. 같은 위치의
`메뉴와 함께 보기`로 복귀한다. 활동이나 계정이 바뀌면 집중 상태를 해제한다.
브라우저 전체화면 API·장치 권한·추가 서버 호출을 사용하지 않는다.

말하기의 카드 선택·이동·삭제와 생성·확인·TTS 핸들러는 그대로 사용한다. 생성 정보와 원래 선택
순서는 접어 확인하며, 만들어진 문장이나 진행 중인 음성이 없을 때 불필요한 발화 조작을 줄인다.
빠른 표현과 복구 표현은 유지한다. 칩의 UID 고정·명시 저장·매 작업 재인증과 공용/개인 적용 규칙도
기존 로직을 사용한다. 리포트는 기존 API의 기록만 표시하며 예시 점수·별·증감률은 추가하지 않는다.
새 녹음·발음 평가·인쇄 기능이나 새 학습·장치 API를 추가하지 않는다.

스타일은 `frontend/src/assets/activityUx.css`의 `.app` 범위에 두어 랜딩과 구분한다.
작은 화면의 단일 패널 배치, 선택 목록 스크롤과 고대비 설정을 고려했으나 실행 검수는 남아 있다.
기존 이미지와 카드 매핑을 재사용하며 참고 PDF·마스코트 변경·Arduino 진단 스케치를 커밋에 넣지 않는다.

## 검증 상태 — 사용자 직접 진행

**이 후속 변경의 테스트·빌드·브라우저 실행 검수는 모두 미실행이다.** 사용자 요청 이후 추가 검사
명령을 실행하지 않았다. 코드와 참고 자료를 읽고 수정했으며, 참고 PDF의 이미지 추출은 자료 확인이다.
앞선 랜딩의 317개 검사·빌드·브라우저 통과 기록은 이 후속 변경을 검증한 결과가 아니다.
본 커밋이나 파일 수정으로 UX·배포·실물 완료를 표시하지 않는다.

사용자가 실행할 때 확인할 범위:

- 말하기에서 카드 선택 순서·추가·이동·삭제와 상단 문장 영역의 터치/키보드 접근.
- 화면이 좁거나 선택 카드·생성 문장이 길 때 고정 영역과 내부 스크롤의 겹침 여부.
- 집중 화면 진입·메뉴 복귀, 활동 전환 뒤 메뉴 표시, 빠른/복구 표현과 재생 제어 접근.
- 단어·소리·문장 순서 연습의 답 선택·재도전·다음 문제·진행/결과 표시.
- 관리자 USB 인식·UID 고정·카드 검색·미리보기·비밀번호 확인·저장·다음 칩·수정/해제.
- 보호자/담당자 연결 권한, 리포트의 빈 기록·집계·기간·내보내기·개인정보 동의 흐름 유지.
- 데스크톱·태블릿·휴대폰, 고대비·동작 줄이기·키보드 표시 상태.

실물 리더기·칩 등록부터 TTS·실제 음질·배포의 기존 미완료 게이트도 별도로 유지한다.
