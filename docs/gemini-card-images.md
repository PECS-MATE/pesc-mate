# Gemini 카드 그림 생성

## 화면과 사용 순서

운영 담당자 계정에서 공용 카드 등록 화면의 **AI 그림 카드**를 선택합니다.
카드 이름과 카테고리를 입력하고, 필요하면 그림 설명을 덧붙입니다.
사용 가능 여부를 확인한 뒤 외부 전송·비용 안내에 동의하고 생성합니다.
미리보기에서 의미를 검토하고 **확인하고 적용**을 누른 다음 공개 범위를 확인해 저장합니다.
생성 자체는 카드를 저장하지 않습니다. 결과를 버리면 DB에 그림이 등록되지 않습니다.

연결 사용자의 개인 카드 등록 및 사진 가져오기에도 같은 그림 생성 도구가 연결되어 있습니다.
기존 카드 관리 권한과 보호자 동의 검사를 그대로 적용합니다.
보호자는 **아이 관리 → 개인 카드 관리 → 개인 카드 등록 → AI 그림 카드**에서 사용합니다.
선택한 아이의 개인 카드로 저장되며 공용 카드로 공개되지 않습니다.

그림 생성에는 [기존 카드 제작 지침](card-image-production-rules.md)의 공통 규격과
분류별 표현 규칙만 적용합니다. 고정 장면은 제외하며 원하는 장면은 설명에 입력합니다.

## OpenRouter 설정 (현재 기본값)

이미 저장한 `OPENROUTER_API_KEY`를 그대로 사용합니다. Google 키를 별도로 발급할 필요는 없습니다.
문장 생성의 `OPENROUTER_MODEL`과 이미지 생성 모델은 별도 설정입니다.

```dotenv
IMAGE_GENERATION_PROVIDER=openrouter
OPENROUTER_IMAGE_MODEL=google/gemini-2.5-flash-image
IMAGE_GENERATION_DAILY_LIMIT=30
```

키가 없을 때만 루트 `.env`에 `OPENROUTER_API_KEY`를 추가합니다.
OpenRouter 계정 잔액과 키의 모델 사용 제한을 확인하세요.
키에 설정한 사용 한도는 실제 충전 잔액과 다릅니다. 무료 계정에서는 유료 이미지 모델을
사용하기 전에 크레딧 충전이 필요합니다.
Google과 OpenRouter에 카드 이름·설명이 전달됨을 화면에서 확인한 뒤 생성합니다.

## Google 직접 연결 (선택)

1. [Google AI Studio API 키](https://aistudio.google.com/api-keys)에서 Google 계정으로 로그인합니다.
2. 사용할 프로젝트를 선택하거나 만들고 API 키를 발급합니다.
3. 프로젝트의 Gemini API 유료 사용·결제·할당량을 확인합니다.
4. 프로젝트 루트 `.env`에 다음 값을 저장합니다. 키는 채팅이나 Git에 올리지 않습니다.

```dotenv
IMAGE_GENERATION_PROVIDER=gemini
GEMINI_API_KEY=발급받은키
GEMINI_IMAGE_MODEL=gemini-2.5-flash-image
IMAGE_GENERATION_DAILY_LIMIT=30
```

PowerShell에서 적용합니다. 환경 변수 변경에는 컨테이너 재생성이 필요합니다.

```powershell
$env:TABLET_BIND_ADDRESS = "0.0.0.0"
docker compose up -d --build
```

PC 접속: http://localhost:5173/ . 다른 기기는 같은 네트워크에서 PC IPv4 주소의 5173 포트를 사용합니다.
Google API 키는 백엔드 환경 변수로만 전달하며 프론트엔드 번들에 포함하지 않습니다.
선택한 제공업체의 키가 없으면 화면은 사용할 수 있으나 유료 생성 버튼은 활성화되지 않습니다.

## 비용 제한

- 한국 시간 자정 기준, 같은 DB를 사용하는 서비스 전체에서 하루 최대 30번의 생성 시도입니다.
- DB의 날짜별 카운터를 조건부 증가시켜 프로세스·서버 재시작 뒤에도 횟수를 유지합니다.
- 설정으로 0~30회까지 낮출 수 있습니다. 30보다 큰 값도 서버에서 30으로 제한합니다.
- 외부 요청 전에 횟수를 차감합니다. 실패·시간 초과에도 반환하지 않고 자동 재시도하지 않습니다.
- 기존 사용자별 시간당 20회 처리 제한과 단일 프로세스 처리 제한도 유지합니다.
- DB 확인에 실패하면 유료 요청을 보내지 않습니다.
- 이는 이 서비스의 호출 횟수 제한이며 Google 계정 전체의 금액 제한은 아닙니다.
  다른 앱의 같은 키 사용, DB 삭제·교체, 모델 변경 등에 따른 비용까지 제한하지 않습니다.
- 생성된 그림은 검토 후 기존 카드 등록을 통해 저장·재사용합니다.

## 검증

Gemini 응답을 모의한 테스트로 그림 미리보기, 설명 전달, 동시 횟수 예약, 한도 초과 차단,
날짜 변경, DB 오류 차단, 실패 요청의 횟수 유지, 동의·키 미설정 처리를 확인했습니다.
프론트엔드에서 동의 전 생성 차단, 결과 확인 후 적용, 한도 소진 차단을 확인했습니다.
Google 직접 연결은 별도 키가 없어 실제 유료 API 생성을 실행하지 않았습니다.
백엔드 관련 테스트 10개와 프론트엔드 테스트 2개가 통과했고 프로덕션 빌드가 완료됐습니다.
OpenRouter 전환 후 관련 백엔드 테스트 15개를 확인했습니다.
2026-11-18 충전 후 최신 키를 컨테이너에 반영하고 실제 물컵 그림 1장 생성에 성공했습니다.
같은 키로 Qwen 문장 생성도 `source=openrouter`, `status=generated`로 확인했습니다.
검증 그림은 로컬 미리보기로만 저장했으며 공용·개인 카드에는 자동 등록하지 않았습니다.
빌드에는 기존 번들 크기·동적 가져오기 관련 경고가 남아 있습니다.

API 형식 참고: [Google 이미지 생성 문서](https://ai.google.dev/gemini-api/docs/image-generation).
