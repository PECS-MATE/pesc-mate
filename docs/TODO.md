## 1. 제품 방향

PESC MATE는 실물 PECS 카드가 늘어날수록 발생하는 휴대·분류·관리 부담을 줄이고, 발화장애 아동이 태블릿 한 대에서 익숙한 그림·사진·글자로 자신의 의사를 음성으로 전달하며 어휘와 의사소통을 학습할 수 있도록 지원하는 개인 맞춤형 디지털 AAC 플랫폼이다.

### 핵심 사용자

- AAC 사용자: 그림·사진·글자를 선택해 문장을 만들고 음성으로 전달한다.
- 보호자: 아동별 카드·빠른 표현·학습 설정·기록을 관리한다.
- 담당자: 보호자가 부여한 아동별 권한 범위 안에서 지원한다.
- 운영 권한 담당자: 별도 역할이 아니라 전체 운영 권한이 추가된 담당자 계정이다.

### 제품 원칙

- 의사소통이 최우선이며 학습·게임·통계 때문에 말하기가 막히면 안 된다.
- 카드 위치는 보호자나 권한 있는 담당자가 바꾸기 전까지 고정한다.
- 추천은 고정 보드를 자동으로 재배치하지 않는다.
- 의사소통 기록과 학습 기록은 저장·조회·통계·보관 목적을 분리한다.
- 학습 기능은 가정에서의 반복 연습과 교육을 위한 핵심 축으로 제공한다.
- 성취 화면은 아동을 평가하는 화면이 아니라 보호자·담당자의 지원 판단 도구로 제공한다.
- AI와 외부 TTS 장애가 기본 카드 탐색과 의사소통을 중단시키면 안 된다.

선행조건: 현재 구현된 고정 복구 영역과 마지막 발화 상태를 그대로 사용한다.

  - ‘잘못 눌렀어요’
  - ‘그 뜻이 아니에요’
  - ‘다시 말할게요’
  - ‘제 말을 기다려 주세요’
  - ‘질문을 잘 모르겠어요’
  - ‘맞아요’
  - ‘아니에요’
- [ ] 필수 고정 표현과 사용자별 교체 가능 표현의 범위 확정
- [ ] 긴급·복구 표현 음성을 로그인 직후 기기에 준비

- [ ] 캐시되지 않은 표현을 눌렀을 때 텍스트 유지와 대체 동작 제공
- [ ] 잘못 누름 → 취소 → 수정 → 다시 발화 시나리오 자동 테스트
- [ ] 실제 태블릿에서 두 번 이하의 선택으로 복구 가능한지 기록

완료 기준: 네트워크가 없는 상태에서도 아동이 잘못 전달한 의사를 최대 두 번의 선택 안에 취소하거나 고쳐 다시 말한다.

- [x] 보호자용 음성·속도·높낮이·기본 볼륨 설정

- [ ] Android 지원 버전별 한국어 로컬 음성 확인
- [ ] iPadOS/Safari 지원 버전별 한국어 로컬 음성 확인
- [ ] Windows/Chrome·Edge 한국어 로컬 음성 확인

완료 기준: 지원을 선언한 입력 장치에서 별도 터치 없이 핵심 의사소통 흐름을 완료한다.

### B2-03. 음성 개인화

- [ ] 선택형 고품질 서버 TTS 공급자 비교
- [ ] 기기 TTS와 서버 TTS의 자동·수동 전환
- [ ] 서버 TTS 실패 시 로컬 TTS 대체
- [ ] 자주 쓰는 문장 음성 캐시
- [ ] 녹음 음성 카드
- [ ] 개인화 음성 사용 동의와 삭제
- [ ] 음성 데이터 외부 전송 최소화
- [ ] 월별 비용 한도와 차단 기준

완료 기준: 개인화 음성을 선택하지 않거나 외부 서비스가 중단돼도 기본 의사소통이 유지된다.

## 10. B3 — 연구·선택형 AI

### B3-01. AI 카드 이미지 생성

- [ ] AI 이미지가 필요한 카드와 실제 사진이 적합한 카드의 기준
- [ ] 생성 스타일, 배경, 인물 표현 일관성
- [ ] 아동에게 혼동을 주는 추상적·유사 이미지 평가
- [ ] 유해 이미지 차단과 보호자 확인
- [ ] 모델, 프롬프트, 생성 시각, 승인 이력
- [ ] 생성 비용 한도와 재시도 횟수
- [ ] 생성 실패 시 직접 사진 업로드 유지
- [ ] 생성 이미지의 이용 조건과 출처 표시

완료 기준: AI 생성이 선택형 카드 제작 도구로만 제공되고 보호자 확인 전 아동 보드에 자동 반영되지 않는다.

### B3-02. AI 대화 연습

- [ ] 실제 의사소통과 분리된 연습 공간
- [ ] 연령이 아닌 의사소통 수준 기반 시나리오
- [ ] 학교, 식사, 병원, 놀이 등 상황
- [ ] 승인된 카드만 응답 선택지로 제공
- [ ] AI가 카드에 없는 의도를 추가하지 않도록 검증
- [ ] 민감정보 입력과 유해 응답 차단
- [ ] 대화 기록 저장 여부를 보호자가 선택
- [ ] 결과를 진단·치료 성과로 표시하지 않도록 제한
- [ ] AI 장애 시 기존 학습과 의사소통 유지
- [ ] 모델·프롬프트 버전과 안전 처리 기록

완료 기준: 대화 연습이 아동의 실제 발화를 대신하지 않고 AI 장애·오류가 기본 기능에 영향을 주지 않는다.

## 11. TRACK B 착수 규칙

- [ ] B1 기능은 A0 완료 후 시작한다.
- [ ] B2 기능은 A1 완료와 실제 사용자 피드백 확보 후 시작한다.
- [ ] B3 기능은 A2 완료와 비용·안전·개인정보 정책 확정 후 시작한다.
- [ ] 새 기능은 고정 카드 위치를 자동 변경하지 않는다.
- [ ] 새 기능은 말하기·긴급 표현·복구 표현을 잠그지 않는다.
- [ ] 새 기능 데이터는 의사소통·학습·운영 중 목적에 맞는 영역에 저장한다.
- [ ] 새 기능마다 권한, 오프라인, 접근성, 삭제, 감사 로그 영향을 검토한다.
