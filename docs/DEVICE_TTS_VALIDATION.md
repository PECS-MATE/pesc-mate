# 기기 TTS 검수표

## 지원 후보

아래 환경은 배포 전 검수 대상이며, 실제 결과가 기록되기 전에는 공식 지원 대상으로
표시하지 않는다.

## 공통 준비

1. OS 설정에서 한국어 음성 데이터를 설치한다.
2. 온라인 상태로 로그인해 음성 설정의 미리 듣기를 실행한다.
3. 앱에 표시되는 로컬 한국어 음성 개수와 선택 음성을 기록한다.
4. 기기 음량을 50% 이상으로 설정하고 무음·방해 금지 모드를 확인한다.
5. 브라우저와 홈 화면 앱을 각각 시험할 경우 결과를 별도 행으로 남긴다.

## 시나리오

### 기본·오프라인

1. `도와주세요`, `잘못 눌렀어요`, 카드 한 장, 완성 문장을 각각 5회 재생한다.
2. 비행기 모드에서 브라우저를 완전히 종료한 뒤 다시 열어 같은 표현을 재생한다.
3. 실패 횟수와 버튼 입력부터 소리 시작까지의 시간을 기록한다.
4. 실패해도 선택 카드, 문장과 전달하려던 표현이 화면에 남는지 확인한다.

### 음량·출력 장치

1. 기본 볼륨을 0으로 설정했을 때 무음 재생 대신 설정 안내가 나오는지 확인한다.
2. 유선 또는 블루투스 출력 장치를 연결하기 전·후에 같은 표현을 재생한다.
3. 연결을 끊은 뒤 기기 스피커로 복귀하는지 확인한다.
4. 웹 앱은 출력 장치를 직접 선택할 수 없으므로 OS 출력 표시와 실제 소리를 함께 확인한다.

### 화면 잠금·앱 전환

1. 문장을 재생하는 동안 화면을 잠그거나 다른 앱으로 전환한다.
2. 진행 중 재생이 취소되고 화면 복귀 후 재생 상태가 `재생 중`으로 남지 않는지 확인한다.
3. `마지막 말 다시 듣기`로 같은 내용을 다시 재생한다.
4. 복귀 후 한국어 음성 목록과 선택 음성이 정상인지 확인한다.

## 통과 기준

- 핵심 표현 오프라인 재생 5회 중 5회 성공
- 일반 상태의 발화 시작 지연 중앙값 500ms 이내 목표
- 음성 실패 시 카드·문장·전달 문구 보존
- 화면 잠금이나 앱 전환 후 유령 재생 상태가 남지 않음
- 출력 장치 변경 후 재시도 경로가 동작함

실패한 환경은 공식 지원 목록에 넣지 않고 OS 음성 설치 안내, 재현 절차와 대체 수단을
함께 기록한다.
