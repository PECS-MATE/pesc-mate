# PECS MATE 발표 대본 — 3분 이내

수정일: 2026-11-18. 현재 promo의 7개 장면 순서에 맞춘 대본입니다.
목표는 **시연 포함 약 2분 45초**이며, 실제 연습에서는 2분 50초 안에 마치도록 합니다.
아래 시간은 배분안으로, 실제 낭독 시간은 초시계로 확인합니다. 대괄호는 읽지 않습니다.

발표 화면: http://localhost:5173/promo-ipad.html

발표 후 질의응답: [예상 질문과 답변](presentation-qa.md)

기술 질의응답: [기술 질문 대비](presentation-technical-qa.md)

## 시작 전 준비

- 발표 화면의 자동 재생을 일시정지하고, 장면은 ‘다음 장면’으로 직접 넘깁니다.
  자동 발표는 75초 반복이라 이 대본의 진행 시간과 일치하지 않습니다.
- 실제 앱과 RFID 확인 화면은 별도 탭에 준비합니다. 리더 연결은 미리 완료합니다.
- 가져온 실제 사용 카드 중 그림이 잘 보이는 한 장을 소개 때 보여줍니다.
  아래 예시의 ‘물’은 실제로 가져온 카드의 그림에 맞춰 바꿉니다.
- RFID 시연용 카드 두 장의 공용 매핑과 실제 음성 출력을 미리 확인합니다.
- 선택한 여자아이/남자아이 음색으로 발표용 문장을 미리 재생해 캐시를 준비합니다.
  현재 로컬 Qwen TTS는 CPU에서 새 음성 생성에 수십 초가 걸릴 수 있습니다.
  발표 도중 처음 합성하는 문장을 기다리는 방식으로 진행하지 않습니다.
- 말하기 음성 시연은 3번 장면에서 한 번만 합니다. 5번 RFID 장면에서는
  문장을 비운 뒤 태그 인식과 카드 추가를 보여 줍니다. 자동 음성이 시작되면
  이미 준비한 짧은 문장만 사용하고, 추가 음성 완료를 기다리지 않습니다.
- Arduino 시리얼 모니터를 닫아 브라우저가 USB 포트를 사용할 수 있게 합니다.
- OpenRouter 문장 생성에는 서버 PC의 인터넷 연결이 필요합니다.
- 실제 시연이 안 되면 재연결에 시간을 쓰지 말고 아래 대체 멘트로 이어갑니다.

## 0:00–0:30 · 1. 서비스 소개 — PECS란?

[서비스 소개 장면. 가져온 실제 사용 카드를 청중에게 보여줍니다.]

안녕하세요. 그림카드로 마음을 전하는 PECS MATE를 소개하겠습니다.
제가 가져온 이 카드는 실제 사용하고 있는 그림카드입니다.
말로 표현하기 어려운 아동이 물을 원할 때, 이 카드를 상대에게 건네 뜻을 전할 수 있습니다.
PECS는 이런 그림카드 교환을 활용하는 의사소통 체계입니다.
저희는 이 경험을 실물 카드와 웹으로 연결했습니다.

## 0:30–0:50 · 2. 제작 배경 — 누구를 위한 서비스인가?

[제작 배경 장면]

주 사용자는 말로 의사를 표현하기 어려운 아동이며,
보호자와 담당자는 카드 등록과 설정을 돕습니다.
카드가 늘어날수록 휴대하고 찾고 관리하기가 번거로워집니다.
그래서 익숙한 카드를 활용하면서 필요한 표현을 디지털로 모을 수 있게 만들었습니다.

## 0:50–1:20 · 3. 말하기 시연 — 카드에서 문장과 음성으로

[말하기 시연 장면. 실제 앱 시연 시 미리 확인한 물·마시다 카드를 선택합니다.]

사용자가 물과 마시다 카드를 고르면 문장 영역에 모입니다.
문장 만들기를 누르면 Qwen이 짧은 한국어 문장으로 다듬고,
로컬 Qwen TTS가 선택한 여자아이 또는 남자아이 음색으로 읽어 줍니다.
생성 결과는 카드 의미와 검증 규칙을 확인하며,
문장 생성에 문제가 생기면 규칙 기반 문장으로 대체합니다.

[실제 음성 시연은 한 번만 실행합니다. 자동 발표 화면은 무음 예시입니다.]

## 1:20–1:40 · 4. 맞춤 카드 — 아이에게 필요한 표현으로

[맞춤 카드 장면]

사용자마다 필요한 표현이 다르기 때문에 보호자가 개인 카드를 등록하고 편집할 수 있습니다.
AI 그림 생성에는 흰 배경과 한 가지 의미 같은 제작 규칙을 적용합니다.
그림은 확인 후 카드에 반영하고, 완성한 카드는 실물로 인쇄할 수 있습니다.

## 1:40–2:10 · 5. RFID 연결 — 실물 카드를 웹으로

[RFID 장면. 실제 앱의 문장을 비우고 매핑된 카드 두 장을 순서대로 태그합니다.
같은 카드를 다시 태그해 문장에 중복 추가되지 않는 것을 짧게 보여 줍니다.]

실물 카드에는 RFID 칩을 연결합니다.
카드를 리더기에 대면 Arduino가 칩을 읽고, USB를 통해 웹으로 전달합니다.
웹에서는 등록된 그림카드를 찾아 문장에 추가합니다.
현재 문장에 있는 카드는 다시 태그해도 중복으로 쌓이지 않습니다.
이렇게 화면 터치와 실물 카드 입력을 함께 사용할 수 있습니다.

## 2:10–2:35 · 6. 발전 과정 — 구현 기술과 향후 계획

[발전 과정 장면]

React 화면과 FastAPI 서버, MongoDB를 연결하고,
문장 생성과 음성 출력, RFID 입력을 하나의 흐름으로 통합했습니다.
문장 AI는 OpenRouter API로, 아이 음색 합성은 로컬에서 실행합니다.
앞으로는 사용자별 학습지 제작과 실제 사용 환경에서의 검증을 진행할 계획입니다.

## 2:35–2:45 · 7. 함께 체험하기 — 마무리

[함께 체험하기 장면]

작은 카드 선택이 나의 목소리가 되도록 돕는 PECS MATE였습니다.
준비한 실물 카드와 화면으로 직접 체험해 보실 수 있습니다. 감사합니다.

## 시연이 지연될 때 대체 멘트

RFID 연결이 지연되면:

> 준비한 화면으로 설명드리겠습니다.
> 실물 카드의 칩을 읽으면 등록된 그림카드가 문장에 추가되는 방식입니다.

음성 생성이 지연되면:

> 문장은 화면에서 확인할 수 있고, 음성은 로컬에서 합성합니다.
> 이어서 실물 카드 연결을 보여 드리겠습니다.

10초 이상 기다리지 말고 다음 설명으로 넘어갑니다. API 응답 시간을 고정된 성능으로
약속하거나 아직 계획인 학습지 기능을 구현 완료로 소개하지 않습니다.
