# 접근성 사용성 평가 시나리오

## 목적과 참여자

PESC MATE의 접근 설정이 실제 AAC 의사소통을 방해하지 않는지 확인한다. 대상 아동, 보호자, 특수교사, 언어재활사가 각각 최소 2명씩 참여하되 아동의 연령, 운동·시각·인지 특성과 익숙한 접근 방법을 기록한다. 이 평가는 진단이나 치료 효과 판정이 아니다.

평가 전에 법정대리인 동의와 아동의 쉬운 말 동의를 받고, 화면·음성 녹화 여부를 별도로 선택하게 한다. 실명과 발화 원문은 결과지에 적지 않는다. 아동이 불편함이나 중단 의사를 표현하면 즉시 끝내며, 의사표현을 유도하거나 정답을 암시하지 않는다.

## 준비

- 스마트폰 세로 화면, 태블릿 또는 PC 중 참여자가 평소 쓰는 기기를 우선 사용한다.
- 기기별 브라우저 확대, 보조공학, 스위치 입력 장치와 조작 자세를 기록한다.
- `도와주세요`, `그만`, `물`, `마시다`, 건강·감각 표현을 포함한 테스트 계정을 준비한다.
- 진행자는 발화 결과가 틀려도 평가하지 않고, 10초 이상 멈춘 경우에만 사전에 정한 단계별 도움을 제공한다.

## 아동 수행 시나리오

1. 로그인 뒤 `도와주세요`를 두 번 이하의 조작으로 발화한다.
2. 그림 중심, 그림+글자, 글자 중심 중 편한 표시를 고르고 `물` 카드를 찾는다.
3. 카드와 글자를 크게 바꾸고 한 페이지 카드 수를 줄인 뒤 `물 → 마시다`를 선택한다.
4. 선택 카드 그대로 발화와 자연스러운 문장을 각각 사용하고 원래 카드 순서를 확인한다.
5. 고대비와 애니메이션·장식 감소를 켜고 같은 표현을 다시 찾는다.
6. 잘못 누른 카드를 삭제하거나 전체를 비우고, 원하면 언제든 `그만`으로 평가 중단을 표현한다.

각 과제에서 성공 여부, 첫 발화까지 걸린 시간, 잘못 선택한 횟수, 되돌리기 횟수와 도움 수준(없음/말 안내/가리키기/직접 조작)을 기록한다. 참여자에게 가장 편한 표시, 힘들었던 조작, 빠진 표현을 쉬운 질문으로 확인한다.

## 보호자·전문가 검토 시나리오

보호자는 다른 기기로 같은 사용자에 로그인해 저장된 접근 설정이 복원되는지 확인한다. 특수교사와 언어재활사는 카드 의미 분류, 글자 가독성, 오조작 위험, 발화 지연, 개인별 조정 범위와 통계 문구가 관찰 사실만 전달하는지 검토한다. 각 검토자는 아동 대신 과제를 수행하는 것이 아니라 아동 수행을 관찰한 뒤 의견을 기록한다.

## 키보드와 스위치 스캐닝 검증

- `Tab`과 `Shift+Tab`만으로 본문 바로가기, 주 메뉴, 빠른 표현, 출력 방식, 카테고리, 카드, 문장 조작 및 접근 설정에 도달한다.
- 모든 포커스 위치에서 4px 외곽선이 보이고, `Enter` 또는 `Space`로 버튼·체크박스·목록을 조작한다.
- 탭 순서는 화면과 DOM의 읽기 순서를 따르며 양수 `tabindex`를 사용하지 않는다.
- 스위치 어댑터는 `[data-scan-group]`을 화면 순서로 읽고 그 안의 활성화된 `button`을 DOM 순서로 순환할 수 있다. 그룹은 빠른 표현, 출력 방식, 카테고리, 카드 목록으로 나뉜다.
- 자동 스캔을 연결할 때 스캔 주기, 일시정지, 역방향 이동과 선택 후 시작 위치를 사용자별로 정하고, 포커스를 강제로 빼앗지 않는다.

## 통과 기준과 결과 기록

- 모든 핵심 버튼은 44×44 CSS px 이상이고 반복 조작 영역 사이 간격은 8px 이상이다.
- 각 아동이 선호 설정에서 `도와주세요`를 도움 없이 두 번 이하의 조작으로 발화한다.
- 접근 설정을 저장한 뒤 로그아웃하거나 다른 기기에서 로그인해도 같은 설정이 복원된다.
- 키보드 경로에 갇힘이 없고 포커스가 화면 밖으로 사라지지 않는다.
- 아동이 원치 않는 발화를 취소하거나 즉시 `그만`을 표현할 수 있다.

결과표에는 익명 참여자 코드, 기기·입력 방식, 시나리오 번호, 성공 여부, 시간, 오조작, 도움 수준, 중단 여부, 관찰 메모와 개선 우선순위를 기록한다. 실패한 과제는 아동의 능력 부족으로 해석하지 않고 UI·어휘·환경 요인으로 나누어 수정 후보를 만든다.
