# 아동 데이터 경계 자동 검증

## 검증 목적

화면에서 메뉴를 숨기는 것과 별개로, 인증 사용자가 다른 아동의 ID나 객체 ID를 직접
전송해도 서버가 데이터를 반환하지 않는지 확인한다. 자동 검증은
`backend/test_data_boundaries.py`에서 실제 FastAPI 라우트를 호출한다.

## 자동 검증 범위

| 요청 주체 | 직접 요청 대상 | 기대 결과 |
|---|---|---|
| AAC 사용자 A | 사용자 B의 대시보드와 의사소통 기록 | 403 |
| AAC 사용자 A | 사용자 B의 음성·접근성 설정 | 403 |
| AAC 사용자 A | 사용자 B의 보드 구성과 변경 이력 | 403 |
| AAC 사용자 A | 사용자 B의 학습 설정·진행·감사 이력 | 403 |
| AAC 사용자 A | 사용자 B의 개인 카드 목록·이미지 | 403 |
| AAC 사용자 A | 사용자 B 기록에 대한 지원 메모 | 403 |
| AAC 사용자 A | 사용자 B의 프로필 이미지 | 403 |
| 운영 권한 담당자 | 연결되지 않은 아동의 기록·프로필·개인 카드 | 403 또는 존재 비공개 404 |

공용 콘텐츠를 승인하는 `content_manage` 권한은 아동별 연결 권한을 대신하지 않는다.
개인 카드 이미지는 운영 권한만으로 조회할 수 없고, 공용 전환을 요청한 카드만 승인
흐름에 나타나야 한다.

## 남은 실제 검증

- 실제 브라우저의 역할별 로그인과 메뉴 우회
- 두 기기에서 연결 회수 직후 열려 있던 화면·직접 URL·재접속 확인
- 프록시나 브라우저 캐시에 민감 응답이 남지 않는지 확인
- 사용자 A/B에 실제 데이터를 만든 뒤 내보내기 결과까지 교차 확인
