# React 컴포넌트 상호작용 테스트

실제 React 컴포넌트를 jsdom에 렌더링하고 Testing Library의 역할·접근 가능한 이름으로
버튼, 라디오, 파일 입력을 조작한다. 소스 문자열 검사로 확인할 수 없는 화면 상태 변화와
비동기 실패를 검증한다. Vitest가 JSX와 `import.meta.glob`을 기존 React 플러그인으로 변환한다.

## 실행

Node.js 22.13 이상인 22.x, 24.x 또는 26 이상을 사용한다. 로컬 검증 버전은 22.20.0이다.
저장소의 `frontend`에서 실행한다.

```powershell
npm ci
npm test
```

- `npm test`: 기존 Node 단위·회귀 테스트 후 컴포넌트 테스트 실행
- `npm run test:unit`: 기존 서비스·소스 회귀 검사만 실행
- `npm run test:components`: 컴포넌트 테스트만 한 번 실행
- `npm run test:components:watch`: 변경한 컴포넌트를 반복 검증

원격 CI는 2026-10-20 사용자 요청으로 제거했다. 컴포넌트 검사는 기존 `npm test`와
루트의 `npm run verify`·`npm run verify:frontend`·`npm run verify:full`에서 계속 실행한다.
테스트 패키지는 개발 의존성이며 정확한 버전과 lockfile로 관리한다.

## 검증 범위

`frontend/test/components/Profile.test.jsx`:

- 선택 전 저장 차단, 키보드 프리셋 선택과 저장 중 중복 조작 차단
- 목록 조회·저장 실패 후 재시도와 선택 유지
- 저장 없이 닫기
- 지원하지 않는 형식·5MB 초과 파일의 업로드 차단
- PNG 교체·업로드와 미리 보기 URL 해제
- 안전성 검사 거절 후 기본 캐릭터로 전환
- 계정 전환 후 늦게 도착한 이전 사진 무시와 이미지 조회 실패 시 대체 표시

`frontend/test/components/App.test.jsx`:

- StrictMode에서 로그인 복원 후 키보드·버튼 카드 선택, 순서 변경·삭제와 로컬 순서 저장
- 문장 생성 실패 후 카드 보존과 선택 순서 그대로 발화
- 동기적인 TTS 실패에도 전달 문구·카드를 유지하고 재생 재시도
- 음량 0일 때 무음 재생·이력 생성 차단과 설정 안내
- 선택 한도 12장 보존
- 이전 발화의 지연 콜백 무시와 현재 발화 이력 보존

`frontend/test/components/SupportRecords.test.jsx`:

- 보호자·담당자의 의사소통·학습 탭과 권한별 조회 범위
- 탭·패널 연결, 방향키·Home·End와 권한 없는 탭 건너뛰기
- 대상 변경 후 늦은 응답과 이전 영역의 늦은 오류 무시
- 오프라인·권한 해제·세션 만료 이후 응답 무시와 지원 기록의 비캐시 유지
- 같은 사용자의 미저장 메모는 탭 이동 시 보존하고 다른 사용자를 선택하면 비우기
- 조회 실패를 0회 지표로 표시하지 않고 다른 허용 영역으로 이동하기

API·음성 엔진·IndexedDB는 테스트 경계에서 대체하며 예상하지 않은 실제 `fetch` 호출은
테스트를 실패시킨다. 파일 시그니처·이미지 정규화·실제 음성 디코딩과 영구 저장은
백엔드 테스트와 [브라우저 E2E](BROWSER_E2E.md)에서 검증한다.
jsdom 테스트는 실제 기기의 음성·터치·화면 배치·스크린리더 검수를 대신하지 않는다.

2026-10-17 컴포넌트 테스트 16개를 통과했다.

2026-10-20 B1 기록 탭 회귀 검사 13개를 포함해 컴포넌트 73개·Node 단위 95개
(총 168개)와 프로덕션 빌드를 통과했다. 전체 Chrome E2E 33개도 별도로 통과했다.
