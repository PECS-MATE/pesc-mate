PESC MATE 과제 계획서

1. 과제의 필요성 및 목표

가. 필요성

기존의 PECS(Picture Exchange Communication System)는 그림이나 사진이
포함된 실물 카드를 활용하여 사용자가 자신의 요구나 의사를 표현할 수
있도록 지원하는 의사소통 방식이다. 그림을 직접 선택하여 의사를 표현할 수
있다는 장점이 있지만, 실물 카드를 지속적으로 제작하고 분류하여 보관해야
하며 사용자가 외출하거나 새로운 환경으로 이동할 경우 필요한 카드를 함께
휴대해야 한다는 불편함이 있다. 또한 카드의 종류가 많아질수록 관리가
복잡해지고 필요한 상황에 적절한 카드를 빠르게 찾기 어려울 수 있다.

이러한 기존 방식의 한계를 보완하기 위해 PECS 카드를 디지털화하여
스마트폰, 태블릿, PC 등 다양한 기기에서 사용할 수 있는 웹 기반 의사소통
시스템을 구축하고자 한다. 별도의 실물 카드를 준비하지 않아도 웹에
접속하여 필요한 카드를 선택할 수 있도록 함으로써 장소와 상황에 따른
제약을 줄이고 사용자의 접근성과 편의성을 높일 수 있다.

특히 단순히 기존 PECS 카드를 디지털 화면으로 옮기는 것에 그치지 않고
인공지능 기술을 활용하여 사용자의 카드 선택 기록과 사용 패턴을
분석한다면 사용자에게 필요한 카드를 우선적으로 추천하는 개인 맞춤형
서비스를 제공할 수 있다. 또한 사용자가 선택한 여러 장의 카드를 AI가
분석하여 자연스러운 문장으로 구성하고 이를 음성으로 출력함으로써 카드
선택에서 실제 의사표현까지 연결되는 통합적인 의사소통 환경을 제공하고자
한다.

사용 과정에서 생성되는 카드 선택 기록과 사용 빈도 등의 데이터를
축적·분석하여 보호자와 교사가 사용자의 의사소통 패턴과 변화를 확인할 수
있는 데이터 기반 관리 환경을 구축할 필요가 있다.

나. 목표

본 과제의 최종 목표는 발화에 어려움이 있는 아동이 그림·사진·글자를
선택하여 자신의 의사를 구성하고, 이를 음성으로 전달할 수 있도록 지원하는
개인 맞춤형 AAC 의사소통 플랫폼 PESC MATE를 구축하는 것이다.

주요 목표는 다음과 같다.

스마트폰, 태블릿, PC 등에서 언제 어디서나 사용할 수 있는 웹 기반
PECS 환경 구축

사용자의 카드 선택 및 이용 기록을 활용한 AI 기반 개인 맞춤형 카드
추천

사용자가 선택한 PECS 카드를 자연스러운 문장으로 확장하는 AI 문장
생성 기능 구현

생성된 문장을 TTS(Text-to-Speech)를 통해 음성으로 출력하여 의사표현
지원

카드 사용 데이터를 분석하여 보호자 및 교사가 확인할 수 있는 관리
대시보드 제공

지속적인 데이터 축적을 통해 사용자 중심의 개인화된 의사소통 지원
환경 구축

최종적으로 PECS 카드 디지털화 → 개인 맞춤형 카드 추천 → 문장 생성 →
음성 출력 → 사용 데이터 분석 및 관리가 하나의 서비스에서 이루어지는
통합적인 의사소통 지원 환경을 구현하는 것을 목표로 한다.

2. 과제 도출 과정 및 참여기업과의 연계 계획

본 과제는 PECS를 활용하는 과정에서 발생할 수 있는 실물 카드의 휴대 및
관리의 불편함과 사용자별 맞춤형 의사소통 지원의 필요성에 주목하여
도출하였다. 기존 PECS의 사용 방식과 한계를 조사하고, 참여기업과의 협의를
통해 실제 서비스 관점에서 필요한 기능과 구현 방향을 구체화하고자 한다.

참여기업과의 협의에서는 웹 기반 PECS 서비스의 활용 가능성, 사용자
편의성, AI 기술 적용 가능성, 서비스의 상품성 및 기술적 구현 난이도 등을
주요 검토 항목으로 설정한다. 이를 바탕으로 단순한 PECS 카드의 디지털화를
넘어 웹 기반 카드 제공, 사용자별 이용 이력 관리, AI 기반 맞춤형 카드
추천, 선택 카드 기반 문장 생성 및 음성 출력, 사용 데이터 분석 기능을
포함하는 플랫폼을 개발한다.

과제 수행 과정에서는 참여기업의 산업체 담당자와 자문 및 협의를 진행한다.
과제 초기에는 서비스의 신규성, 상품성, 기술적 난이도 및 실제 활용
가능성에 대한 의견을 받아 개발 범위와 핵심 기능을 조정한다. 개발
단계에서는 시스템 구조, AI 기능의 적용 방법, 사용자 인터페이스 및 실제
서비스 적용 시 고려해야 할 사항 등에 대해 필요시 자문을 받아 개발 과정에
반영한다.

프로토타입 개발 이후에는 참여기업 담당자에게 주요 기능을 시연하고 사용
편의성, 기능 완성도, AI 기능의 적절성 및 향후 서비스 확장 가능성 등에
대한 피드백을 받는다. 해당 피드백을 바탕으로 UI/UX와 주요 기능을
보완하여 최종 결과물의 완성도를 높인다.

과제 종료 이후에는 참여기업과 함께 실제 현장 또는 관련 서비스에서의 활용
가능성을 검토하고, 사용자별 카드 추천 고도화, 카드 데이터 확장, 모바일
환경 최적화 및 데이터 분석 기능 개선 등 후속 개발 방향을 도출한다.

3. 과제의 기술적 내용 및 수행방법

가. 기술적 내용

1) 웹 기반 PECS 시스템 구축

React 등의 웹 프레임워크를 활용하여 스마트폰, 태블릿 및 PC에서 사용할 수
있는 웹 기반 PECS 시스템을 구축한다. 사용자가 원하는 그림 카드를 쉽게
확인하고 선택할 수 있도록 이미지 중심의 직관적인 UI를 구성하며, 카드의
종류와 목적에 따른 카테고리 분류 및 탐색 기능을 제공한다.

사용자가 선택한 카드는 순서대로 화면에 표시하고 선택 취소, 순서 변경 및
초기화 등의 기능을 제공한다. 다양한 화면 크기에서도 사용할 수 있도록
반응형 웹 구조를 적용한다.

2) 사용자 및 PECS 카드 데이터 관리

사용자 정보, PECS 카드 정보, 카드 카테고리, 카드 선택 기록, 사용 시간 및
카드 조합 등의 데이터를 데이터베이스에 저장·관리한다.

백엔드 API를 통해 프론트엔드와 데이터베이스를 연동하고, 사용자의 카드
선택 이력을 축적한다. 축적된 데이터는 개인 맞춤형 카드 추천 및 사용자
의사소통 패턴 분석에 활용한다.

3) AI 기반 개인 맞춤형 카드 추천

사용자의 과거 카드 선택 데이터를 기반으로 카드별 사용 빈도, 최근 사용
기록 및 함께 선택되는 카드 조합 등을 분석하여 다음에 사용할 가능성이
높은 카드를 추천한다.

초기에는 사용 빈도와 카드 간 연관관계를 활용한 추천 방식을 적용하고,
데이터가 충분히 축적되면 사용자별 사용 패턴을 반영하여 추천 기능을
고도화할 수 있도록 설계한다.

4) AI 기반 자연어 문장 생성

사용자가 선택한 PECS 카드의 의미와 순서를 AI가 분석하여 실제 의사소통에
활용할 수 있는 자연스러운 문장으로 변환한다.

예를 들어 나 → 물 → 마시다 카드를 선택한 경우
저는 물을 마시고 싶어요.와 같이 자연스러운 표현으로 확장한다. 생성형
AI 또는 자연어처리 기술을 활용하되 선택한 카드의 핵심 의미가 변경되지
않도록 구성한다.

5) TTS 기반 음성 출력

AI를 통해 생성된 문장을 TTS(Text-to-Speech) 기술과 연동하여 음성으로
출력한다. 이를 통해 사용자가 직접 말로 표현하기 어려운 상황에서도 선택한
카드의 내용을 주변 사람에게 전달할 수 있도록 한다.

전체 이용 흐름은 카드 선택 → 문장 생성 → 문장 확인 → 음성 출력으로
구성한다.

6) 사용 데이터 분석 및 관리자 대시보드

서비스 이용 과정에서 축적되는 데이터를 활용하여 카드별 사용 횟수, 자주
선택하는 카드, 카테고리별 이용 빈도 및 자주 함께 사용하는 카드 조합 등을
분석한다.

분석 결과를 그래프와 수치 등을 활용한 대시보드 형태로 제공하여 보호자
또는 교사가 사용자의 PECS 이용 현황과 의사소통 패턴을 확인할 수 있도록
한다.

7) 서비스 통합 테스트 및 개선

실제 서비스 이용 흐름을 기반으로 테스트 시나리오를 구성하여 PECS 카드
탐색 및 선택, AI 카드 추천, 문장 생성, TTS 음성 출력, 데이터 저장 및
대시보드 등 주요 기능이 정상적으로 연결되는지 검증한다.

PC뿐만 아니라 스마트폰과 태블릿 환경에서도 기능 및 UI 테스트를 진행하고,
발견된 오류와 사용상의 불편 사항을 개선한다. 이후 참여기업 담당자의
피드백을 반영하여 최종 결과물을 완성한다.

나. 활용 도구·장비·재료 및 기술

웹 개발: React 등 웹 프레임워크

AI: 카드 추천 알고리즘, 자연어처리 및 생성형 AI 기술

음성: TTS(Text-to-Speech)

협업 및 형상관리: Git / GitHub

프로젝트 관리: Jira

테스트 장비: PC, 스마트폰, 태블릿 등

서비스 테스트 및 최종 시연 과정에서 추가 장비나 재료가 필요한 경우 과제
재료비를 활용하여 확보할 예정이다.

4. 기대효과

본 서비스는 기존 실물 PECS 카드를 온라인 환경으로 확장함으로써 카드의
휴대와 보관에 따른 불편을 줄이고, 스마트폰이나 태블릿 등 사용자가 쉽게
접근할 수 있는 기기를 통해 시간과 장소의 제약 없이 의사소통할 수 있는
환경을 제공할 것으로 기대된다.

AI 기반 개인 맞춤형 카드 추천 기능을 통해 사용자가 자주 사용하는 카드와
카드 조합을 분석하여 필요한 카드를 보다 빠르게 찾을 수 있도록 지원할 수
있다. 사용 데이터가 축적될수록 사용자 개인의 의사소통 특성을 반영할 수
있어 개인화된 PECS 환경으로 발전할 수 있다.

또한 사용자가 선택한 카드를 자연스러운 문장으로 변환하고 이를 음성으로
출력함으로써 단순한 그림 또는 단어 선택을 넘어 보다 구체적인 의사표현을
지원할 수 있다. 이를 통해 사용자와 보호자, 교사 및 주변 사람 간의
의사소통 편의성을 높일 수 있을 것으로 기대된다.

사용 과정에서 축적되는 데이터를 분석하여 보호자와 교사가 사용자의 카드
이용 빈도, 주요 표현 및 자주 사용하는 카드 조합 등을 확인할 수 있으며,
이를 지속적인 의사소통 지원에 활용할 수 있다.

향후에는 사용자별 카드 이미지 등록, 상황 및 시간대 기반 카드 추천, 추천
모델 고도화, 다양한 음성 선택 및 모바일 환경 최적화 등의 기능을 추가하여
서비스의 활용 범위를 확대할 수 있다. 궁극적으로 PESC MATE를 PECS의
디지털화뿐만 아니라 AI 기반 개인화, 문장 생성, 음성 출력 및 데이터
분석을 통합한 의사소통 지원 플랫폼으로 발전시키는 것을 기대한다.
