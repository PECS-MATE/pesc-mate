# AI 카드 그림 제작 규칙

사용자가 제공한 2026-10-31 제작 지침에서 공통 규격과 표현 방식만 적용합니다.
2026-11-18 요청에 따라 41종 고정 장면은 생성 참고 자료에서 제외했습니다.

- 불투명 흰 배경 #ffffff, 1:1, 목표 1024×1024px PNG·sRGB.
- 사방 약 10% 여백, 핵심 대상 약 65~75%, 한 장에 한 가지 의미.
- 마스코트·장식·글자·숫자·워터마크·UI 테두리를 제외합니다.
- 사물은 사진형, 행동·감정·신체·관계는 단순 2D 그림상징을 기본으로 합니다.
- 자연색과 식별 특징, 행동의 접촉·방향·자세를 유지합니다.
- 성별·외모·원인·장소를 의미 조건으로 임의 추가하지 않습니다.
- 물/마시다, 밥/먹다, 만족/긍정 응답 등 기본 의미 구분 원칙을 지킵니다.
- 고정된 구도나 특정 장면을 넣지 않습니다. 원하는 장면은 사용자가 설명합니다.

[서버 규칙 자료](../backend/app/data/card-image-guidelines.json)의 공통 규칙과
분류별 사진형/그림상징 규칙을 제공하며 벡터 DB나 추가 모델 호출은 사용하지 않습니다.
규칙은 사용자 설명보다 우선하도록 요청하고 설명은 별도 데이터로 전달합니다.

1024px·PNG·여백은 프롬프트의 제작 목표입니다. 실제 파일 형식·배경·의미 준수의
자동 검증이나 임상 표준·PECS 인증을 뜻하지 않습니다. 기존 미리보기와 WebP 저장,
사람의 확인 후 카드 등록 흐름을 유지합니다. 개인 사진 자동 전송이나 실제 사진 편집은
추가하지 않았으며 기존 카드·ID·RFID 매핑도 자동 변경하지 않습니다.
