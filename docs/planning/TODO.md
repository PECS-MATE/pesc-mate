## 1. 제품 방향

PESC MATE는 실물 PECS 카드가 늘어날수록 발생하는 휴대·분류·관리 부담을 줄이고, 발화장애 아동이 태블릿 한 대에서 익숙한 그림·사진·글자로 자신의 의사를 음성으로 전달하며 어휘와 의사소통을 학습할 수 있도록 지원하는 개인 맞춤형 디지털 AAC 플랫폼이다.

### 핵심 사용자

- AAC 사용자: 그림·사진·글자를 선택해 문장을 만들고 음성으로 전달한다.
- 보호자: 아동별 카드·빠른 표현·학습 설정·기록을 관리한다.
- 담당자: 보호자가 부여한 아동별 권한 범위 안에서 지원한다.
- 운영 권한 담당자: 별도 역할이 아니라 전체 운영 권한이 추가된 담당자 계정이다.

### 제품 원칙

- 의사소통이 최우선이며 학습·게임·통계 때문에 말하기가 막히면 안 된다.
- 카드 위치는 보호자나 권한 있는 담당자가 바꾸기 전까지 고정한다.
- 추천은 고정 보드를 자동으로 재배치하지 않는다.
- 의사소통 기록과 학습 기록은 저장·조회·통계·보관 목적을 분리한다.
- 학습 기능은 가정에서의 반복 연습과 교육을 위한 핵심 축으로 제공한다.
- 성취 화면은 아동을 평가하는 화면이 아니라 보호자·담당자의 지원 판단 도구로 제공한다.
- AI와 외부 TTS 장애가 기본 카드 탐색과 의사소통을 중단시키면 안 된다.

- [ ] 생성 실패 시 직접 사진 업로드 유지
- [ ] 생성 이미지의 이용 조건과 출처 표시

완료 기준: AI 생성이 선택형 카드 제작 도구로만 제공되고 보호자 확인 전 아동 보드에 자동 반영되지 않는다.

### B3-02. AI 대화 연습

- [ ] 실제 의사소통과 분리된 연습 공간
- [ ] 연령이 아닌 의사소통 수준 기반 시나리오
- [ ] 학교, 식사, 병원, 놀이 등 상황
- [ ] 승인된 카드만 응답 선택지로 제공
- [ ] AI가 카드에 없는 의도를 추가하지 않도록 검증
- [ ] 민감정보 입력과 유해 응답 차단
- [ ] 대화 기록 저장 여부를 보호자가 선택
- [ ] 결과를 진단·치료 성과로 표시하지 않도록 제한
- [ ] AI 장애 시 기존 학습과 의사소통 유지
- [ ] 모델·프롬프트 버전과 안전 처리 기록

완료 기준: 대화 연습이 아동의 실제 발화를 대신하지 않고 AI 장애·오류가 기본 기능에 영향을 주지 않는다.
